# 网页面板设计规范

本规范约束 NeoBot 面板的视觉与布局实现。修改页面前先确定内容边界和滚动容器，再添加组件与业务样式。颜色、字体、尺寸与间距统一引用 [tokens.css](./src/styles/tokens.css)，不要在单页定义另一套主题。

## 视觉基线

沿用旧版 sky 天蓝色阶，以冷白与淡蓝画布、内容层和留白区分层级；深色使用藏蓝背景与分层表面。蓝色用于主要操作、当前选择与少量强调，成功、警告、错误继续使用各自状态语义。信息分组优先使用标题与间距，避免每个数字或字段都再套一层卡片。

| 语义        | 浅色值    | 深色值    | 使用位置           |
| ----------- | --------- | --------- | ------------------ |
| `--bg`      | `#f6fcff` | `#0f2238` | 页面画布           |
| `--panel`   | `#ffffff` | `#19304c` | 卡片、工作区内容层 |
| `--panel-2` | `#eef9ff` | `#122a43` | 次级区域、轻量分组 |
| `--text`    | `#1f3a4d` | `#e7f6ff` | 主要文字           |
| `--muted`   | `#526e80` | `#9cb7cb` | 辅助说明           |
| `--brand`   | `#0369a1` | `#7dd3fc` | 主按钮、当前选择   |

以上值由 `tokens.css` 定义，业务 CSS 只使用变量。旧版 `#7dd3fc / #38bdf8 / #0ea5e9` 蓝阶保留；正文、按钮与辅助说明使用对比足够的深浅色组合。暗色主题通过 `html[data-theme='dark']` 切换表面、边框与文字；不得在页面内硬编码白底、黑字或只适用于浅色的透明遮罩。状态文案必须说明含义，不能只靠颜色辨认。

## 字体与信息层级

- 正文使用 `--font-sans`，页面标题使用 `--font-display`，代码、路径和技术标识使用 `--font-mono`。中文优先选本机已安装的 Noto Sans SC，回退 Microsoft YaHei UI、PingFang SC 等系统字体。
- Inter、Plus Jakarta Sans、JetBrains Mono 的西文子集本地分发；不要引入外部字体请求，也不要为普通中文标签强制使用等宽字体。
- 页面标题桌面 20px、手机 19px，区块标题 14–16px，正文 13–14px，辅助说明通常 12px。不要通过不断缩小字号解决拥挤，先调整布局和信息分组。
- 数量、金额、Token、延迟使用等宽数字 `font-variant-numeric: tabular-nums`；数据表中的数字列右对齐，表头与对应数据保持同一对齐方式。
- 长名称、路径、URL 必须在限定宽度内换行或省略。省略显示要能查看完整值，不能只用 `overflow: hidden` 静默裁掉内容。
- 禁止使用 emoji。导航、按钮、状态图标统一使用 Lucide SVG；图标本身不替代可见文字或无障碍名称。

## 页面边界与间距

业务页面根容器统一使用 `.page`，不要用单页 `max-width`、额外左右 padding 或独立 margin 改变外边界。阅读宽度需要收窄时，限制内部正文区域，不移动页面标题和整体内容边界。

| 参数         | 令牌 / 约定                                                               |
| ------------ | ------------------------------------------------------------------------- |
| 页面宽度上限 | `--page-max-width: 1600px`，居中且 `width: 100%`                          |
| 页面左右边距 | `--page-gutter: clamp(20px, 2vw, 32px)`；小屏按同一令牌切换至 20px / 16px |
| 页面区块间距 | `--page-gap: 28px`；手机 20px                                             |
| 卡片内边距   | `--card-padding: 24px`；手机 20px                                         |
| 控件圆角     | `--radius-control: 8px`                                                   |
| 卡片圆角     | `--radius: 12px`                                                          |
| 大容器圆角   | `--radius-large: 16px`                                                    |

间距采用 4px 基础刻度：4 / 8 / 12 / 16 / 20 / 24 / 28 / 32 / 40。相关组件复用同一令牌，不因为属于不同页面就使用不同的卡片内边距、控件高度或圆角。边框、图标描边等细节不受间距刻度限制。

标题统一使用 `PageHeader`，只显示标题与操作，不在标题旁附加说明小字。手机端同样优先保持标题与主要操作同行。页头与正文的间隔保持紧凑，不把呼吸感变成多层空白。配置分类 Tab 放在页头右侧，窄屏独占下一行；本体编辑工具栏集中模式、搜索、校验、同步状态与保存操作，不再另设底部保存栏。窄屏保留保存主操作，其余运行操作收入顶部菜单；撤销、恢复默认、重新读取等次级动作按需打开。面包屑、标题、卡片和工作区的左右边界须对齐。

## 滚动契约

`html`、`body`、应用外壳不承担业务滚动。页面只选择下面一种外层模式，不用固定 `vh` 数值减去猜测的标题高度。

| 模式       | 页面                                             | 滚动位置                                                             |
| ---------- | ------------------------------------------------ | -------------------------------------------------------------------- |
| 一屏总览   | 仪表盘、机器人、系统状态、用量统计、提示词分析   | 外层不滚动；列表按区域高度分页，小屏切换内容视图；原文在阅读区内滚动 |
| 普通页面   | 定时任务                                         | `.content` 负责纵向滚动                                              |
| 工作区页面 | 快捷部署、配置、插件、提示词、聊天流、档案、日志 | `.content--viewport` 不滚动，具体列表或正文区域滚动                  |

工作区根节点使用 `.page.page--viewport`。标题、筛选或保存操作区保持稳定，内容区使用 `flex: 1`、`min-height: 0`，需要收缩的网格列使用 `minmax(0, 1fr)`。通用两栏结构复用 `WorkspaceLayout`，实际滚动放在 `.workspace-scroll` 或页面明确命名的列表 / 正文区域。

需要遵守的边界：

1. 不把已有内滚动的工作区再放入可滚动的 `.content`，避免滚轮在两层页面之间切换。
2. 标题、工具栏、保存区和空状态不应因固定最小高度制造多余滚动。短内容不显示无意义的滚动条，长内容能够到达末尾。
3. 表格横向滚动放在 `.table-scroll` 等表格包装层中；不要在整张带图表或浮层的卡片上设置 `overflow-x: auto`。可横滚区域提供键盘聚焦与可理解的名称。
4. 展开的阅读原文随所属正文容器滚动，不再套 40vh、60vh 等独立滚动盒。可编辑的 textarea、代码编辑器和长弹窗正文可以有必要的内滚动。
5. 侧栏导航保留滚动、触控与键盘可达性，但隐藏常驻轨道；不可用 `overflow: hidden` 代替。正文与表格的滚动提示不应被全局隐藏。
6. 窄屏根据工作区任务改为分步选择或单列内容，仍保留明确的滚动归属。禁止通过裁掉溢出内容来使页面表面上没有横向滚动。

## 组件与状态

- 操作复用 `Button`，表单行复用 `FormField`。保存、校验、重载等操作反馈统一通过全局 `infoBar()`，不在页面另塞结果卡、成功条或重复 toast。同一时间仅一条短摘要，详细字段和恢复操作按需打开；失败、冲突和需重启反馈保持可访问。真正阻塞的读取错误与字段级错误可使用原位错误状态或 `InlineAlert`，不把每次轮询失败都变成通知。
- 所有业务页面自动更新，不放常驻刷新按钮；失败区域保留「重试读取」，不打断已有内容。编辑文档仅在无草稿、无忙碌操作且未聚焦输入时自动同步；非法 JSON 与弹窗交互也会暂停文档替换。请求返回时再次检查编辑世代，不覆盖途中输入，也不悄悄抬高草稿的保存版本。人工放弃草稿和冲突恢复仍明确确认。重载运行时、重启等动作保留各自业务名称。
- 总览复用 `MessageTrendCard`，提供 7 / 30 天、总量、日均、峰值与日期刻度；`LineChart fit` 按容器实测宽高绘制。消息日期读取接口 `date`，延迟时间读取 Unix 秒 `ts`，兼容旧 `at`。
- 系统资源按 CPU 仪表、内存容量与磁盘占比区分视觉层次，图形只表达真实采样，不使用虚构历史曲线。缺失数据与真实 0 值分别呈现，主机信息和更新状态保持可读。
- 部署采用五步导航、单步内容和固定保存栏。切步保留草稿，统一保存只合并实际改过的字段；部分成功时保留失败部分供重试。
- 模型分配按用途组织卡片，单选复用 `SelectControl` 并保留推荐类型分组；选择器、供应商 / 模型和状态放在一起。「运行时已注册」只表示模型已加载，不等于这次分配已经重载生效。模型库合并名称/引用名与类型，状态分为运行和计费两行，避免连续堆叠标签，行内操作保持固定间距。
- 插件只保留一份身份与操作区，版本和能力等详情进入信息弹窗；提示词使用目录、编辑与预览工作台，窄屏切换编辑 / 预览，帮助和占位符按需展开。
- 插件左右底栏共用 grid 行，不能靠两个独立的固定高度对齐。TOML 以剩余高度布局；嵌套配置标题不吸顶，集合条目与分组不要重复叠加缩进线。提示词单键分区只保留一行，多键分区才展开子项。
- 配置分区名称与数量收成一行，描述和生效方式通过信息入口查看，不再重复三层标题。正常生效方式只说明一次，不在每行重复贴热重载标签；需要重启的例外和原因仍保留，能力缺失时不能推定为支持重载。
- 弹窗正文与首个字段只保留一层内边距；长表单使用固定 footer，保存操作不随正文滚走。定时任务的时间字段宽屏并排，窄屏单列，不套用配置页的双栏字段布局。
- 定时任务在手机上改为纵向卡片，标题、状态、触发时间与编辑操作直接可达；长绑定按需展开。手机编辑使用全高面板和至少 44px 的触控区域，不以横向大表格代替移动布局。
- 聊天流将身份与视图切换合并为紧凑工具栏，消息正文优先。隐私与保留说明、后台任务和调用元信息按需查看；折叠长 system 指令时仍保留明确入口和原文。
- 用量页复用自适应趋势图与分页明细；负数域必须包含冲抵值，面积填充回到零基线。小时与日刻度区分，汇总简写不能替代悬停详情或原始明细。
- 提示词分析按 Agent 切换，组成图、来源列表和原文各自有明确边界。系统页的「运行设置」分组展示运行控制、可选扩展和面板安全，修改密码入口放在面板安全，进程操作固定在底部。星舰默认不加载，开关读回真实插件及扩展状态后才显示成功。
- 同一区域优先保留一个主操作；次要动作与删除、关闭等危险操作分组。按钮使用具体中文动词，图标按钮必须有无障碍名称。
- 空态给出内容缺失原因或下一步；读取失败不能表现成正常的零值或空列表。已有数据刷新失败时保留数据，并明确读取状态。
- 页面重新排版不能破坏只读、busy、dirty、版本冲突、密钥只写不读和危险操作确认。后台轮询不能覆盖尚未保存的草稿。
- 页面编辑会话通过 `useEditorGuard` 发布 dirty / busy；页内确认使用 `confirmAction()`，浏览器关闭或刷新保留原生 `beforeunload`。非法 JSON 在当前字段编辑器中的保留范围与限制见 [README](./README.md#约定改代码前请先读)。
- 所有可交互控件保留可见的键盘焦点；减少动态效果偏好生效时关闭非必要动画。高层级浮层使用 `--z-*` 令牌，不添加任意层级数字。
- 页面与组件入场使用统一 Motion 配置，120–220ms 为主，分组交错延迟总量不超过约 150ms。只动画 opacity 与少量位移，不改变滚动容器尺寸；普通轮询、逐行日志和编辑器文本不反复入场。退出页面立即释放旧表单，避免动效期间旧编辑状态影响新页面。
- 登录页例外使用 GSAP 编排一次约 1.6 秒的叠字开场，不再叠加路由 Motion。左侧只保留三行 NEOBOT，描边与实心错位叠放，无额外图标、说明或标签；表单始终可操作，减少动态效果时直接显示最终构图。卸载与偏好切换清理时间轴及内联样式，不能影响输入和焦点。
- TOML 使用共享 CodeMirror 入口，语法颜色覆盖明暗主题；工具栏提供查找、定位、注释、缩进和撤销重做。保留加载失败文本框、只读浏览、快捷键帮助以及 Esc 后 Tab 离开编辑区的入口，不以自动格式化改写用户注释或结构。
- 提示词复用编辑器的纯文本模式，保留查找替换、缩进、撤销和快捷保存；占位符插入替换当前选区，不用拼接字符串破坏光标与撤销历史。
- 页面切换与首次读取用布局对应的骨架，不以一行加载文字替换整页；骨架遵循减少动态效果偏好。下拉筛选共用 `SelectControl`，同一工具栏的标签、选择器与搜索框共享高度。
- 聊天流与档案使用统一记录列表，选中、悬停、类型、时间和长标识清晰区分。系统服务、任务与用量行保留左右内边距，后台任务优先展示状态和真实进度，未知数据按需展开。
- 提示词历史以日期分组、编号与时刻优先，每条默认两行；当前与最新标记分开，存储、模型、图片等详细元信息通过独立入口展开。档案详情的身份、编辑操作与 AI 压缩分组，完整 key、时间和标签按需展开；手机以整组换行，不堆成长串技术信息。
- 新布局必须保留现有业务功能和接口语义；不要为了适应设计隐藏必需操作、冲突详情或失败原因。

## 样式职责

所有全局样式只在 `main.tsx` 导入，顺序以该文件为准。页面组件不要自行导入全局样式，也不要通过增加选择器权重反复盖住旧规则；调整布局时同步移除被替代的约束。

| 文件                                 | 职责                                                     |
| ------------------------------------ | -------------------------------------------------------- |
| `tokens.css`                         | 颜色、字体、尺寸、间距、层级与动效的唯一语义来源         |
| `fonts.css` / `tailwind.css`         | 本地字体与工具类桥接，不另建视觉令牌                     |
| `theme.css`                          | 页面骨架、标题、基础控件、卡片、弹窗、焦点与减少动态效果 |
| `shell.css`                          | 应用外壳、导航、面包屑、内容边距、登录页与待机横幅       |
| `workspace.css`                      | 通用双栏工作区与窄屏主从切换                             |
| `config-workspace.css`               | 配置页面、工具栏、同步状态与保存操作                     |
| `config-tree.css`                    | 配置分区导航、分组内容与说明入口                         |
| `environment.css`                    | 环境变量与供应商的对齐表格、新增行                       |

# 02 快速开始

本文介绍如何从零开始运行 NeoBot。安装部分与项目 [README](../README.md) 一致，这里补充数据目录、配置与常见问题。

> 部署使用者请优先看 [08-部署说明](./08-部署说明.md)：uv / pip / 源码三种安装方式、数据目录、以及 NapCat 反向 WebSocket 的完整配置步骤。

## 环境要求

- Python 3.13 或更高版本
- 操作系统：Windows / Linux / macOS
- 一个 OneBot 框架（如 [NapCat](https://napneko.github.io/)），用于连接 QQ

## 安装

推荐在虚拟环境中安装：

```bash
python -m venv neobot-env
# Windows
neobot-env\Scripts\activate
# Linux / macOS
source neobot-env/bin/activate

pip install neobot-app
```

## 首次运行

```bash
# 首次运行（会自动生成配置文件与目录结构）
neobot

# 编辑 .env 文件填入 API 密钥
# 编辑 data/config.toml 设置机器人 QQ 号

# 启动 OneBot 框架（如 NapCat），然后再次运行 NeoBot
neobot
```

首次运行会自动生成必要的配置文件和目录结构。编辑好配置后，NeoBot 会等待 OneBot 框架连接，连接成功后即可在 QQ 上使用。

## 数据目录

NeoBot 的数据目录默认为 `app/data/`（开发环境），可通过环境变量 `NEOBOT_DATA_DIR` 覆盖。主要内容：

| 路径 | 说明 |
|---|---|
| `config.toml` | 主配置文件（机器人、聊天、模型、Agent 等） |
| `.env` | 环境变量（API 密钥等敏感信息） |
| `plugins_data/` | 插件数据目录；网页面板的密码哈希写在 `plugins_data/dashboard/auth.json` |
| `browser/profiles/` | 浏览器用户数据目录（手动登录会话） |
| `tts/` | TTS 生成的语音文件 |
| `emoji/ creator/gallery/ sandbox/` | 表情包、图库、沙箱文件 |

> 完整的配置项说明见 [05-配置参考](./05-配置参考.md)。

## 连接 OneBot

NeoBot 通过 WebSocket **反向连接** OneBot 框架：

1. 在 OneBot 框架（如 NapCat）中配置 WebSocket 服务端地址为 NeoBot 所在机器的地址与端口（见 `data/config.toml` 中 `adapter` 配置）。
2. 启动 OneBot 框架，再启动 NeoBot。
3. NeoBot 启动后会自动连接，连接成功即可在 QQ 上使用。

### 本地适配器（测试用）

NeoBot 自带本地适配器（`packages/adapter/src/neobot_adapter/local/`），无需 OneBot 框架即可运行，便于开发调试。本地适配器监听 HTTP/WebSocket 端口（默认 `8090`，见配置 `adapter` 段）。

## 网页面板

NeoBot 的网页面板是**官方内置插件 dashboard**（基于 aiohttp），随主进程启停，默认开启：

- 默认监听 `0.0.0.0:9981`（对网络开放），本机访问 `http://127.0.0.1:9981/`；只想本机使用时把 `host` 改为 `127.0.0.1`
- 端口被占用时，从 `port` 起**最多向后尝试 10 个端口**，并在启动日志打印告警提示实际端口
- 登录方式是**面板密码**：未设置密码时不允许外网访问，请在本机打开面板按提示设置密码（至少 8 个字符），或由超级管理员在 QQ 私聊发送 `/set_password <新密码>`（留空自动生成随机密码）。密码以 PBKDF2 哈希保存在 `plugins_data/dashboard/auth.json`
- 页面包含：仪表盘（运行概览/系统资源/消息趋势/最近日志）、插件管理（官方/第三方分组、启停、热重载能力标注、安装/更新/卸载、在线配置、下载代理）、配置管理（本体 `config.toml` 与 `.env` 在线编辑、一键添加 API 供应商、模型库、模型分配、撤销/历史/恢复默认、热重载标记）、用量统计（金额与 Token 图表）、系统状态、机器人详情、日志
- 支持「重载运行时配置」（等价 `config.reload` 命令，也可由超级管理员在 QQ 私聊发送 `/reload`），重载后会列出「已生效 / 需重启」的配置项；另有「重启 NeoBot」
- 面板自身不能在面板内停用或重载（会中断连接）：把 `data/plugin_state.json` 里 `dashboard` 的 `enabled` 改为 `false` 后重启
- `allow_remote_manage = false` 时远程只能查看，不能改配置、编辑 `.env`、管理插件或重启
- 密钥类变量在面板中**只写不读**：只显示是否已设置，保存后也无法再读回明文

面板配置是插件自己的配置文件 `data/plugins_data/dashboard/config.toml`（默认值如下，可在面板「插件 → dashboard → 配置」里改）：

```toml
host = "0.0.0.0"
port = 9981
```

是否启用不是配置项：默认启用，只由 `data/plugin_state.json` 的独立记录决定。

登录密码不在此配置：忘记密码时由超级管理员再次执行 `/set_password` 重置，或停止 NeoBot 后删除 `plugins_data/dashboard/auth.json`，再从本机重新设置。

公网使用时建议通过 HTTPS 反向代理访问，并在确认 HTTPS 生效后将 `secure_cookies` 设为 `true`；只有可信反向代理正确覆盖客户端地址头时才应开启 `trust_proxy_headers`。

> 详细说明见 [04-功能文档/网页面板](./04-功能文档/网页面板.md)。

## CLI 命令

```bash
neobot                      # 启动机器人主程序
neobot firewall-open        # 为网页面板端口添加 Windows 防火墙入站放行规则（需管理员权限，默认放行 9981）
neobot open_web [URL]      # 启动有头浏览器供手动登录认证，会话持久化供后续无头复用
```

## 常见问题

**Q：网页面板外部无法访问？**
A：请放行操作系统和云平台防火墙中的实际面板端口（端口被占用时会向后尝试最多 10 个端口，实际端口见启动日志告警）。可运行 `neobot firewall-open` 添加 Windows 防火墙规则。

**Q：如何重载配置？**
A：网页面板的「配置管理」支持保存并重载（等价 `config.reload` 命令），面板内也可直接「重启 NeoBot」。注意：部分构建期组件（运行中的 LLM Provider、关键词规则、TTS/表情包等）需要重启后才生效。

**Q：配置格式？**
A：主配置为 TOML（`data/config.toml`），API 密钥等敏感信息放入 `.env`。配置加载器会自动迁移旧版本配置并备份。

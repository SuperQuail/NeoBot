# 07 插件开发

NeoBot 通过 **neobot-modloader** 从文件系统目录加载 Python 插件。本文是插件开发的入门指南；**完整 API 文档见 [packages/modloader/README.md](../packages/modloader/README.md)**（747 行，含全部注册方式与示例），以下仅做概览与示例。

## 插件结构

插件可以是单个 Python 文件：

```text
plugins/
  ping.py
```

也可以是一个包：

```text
plugins/
  weather/
    plugin.toml
    __init__.py
```

插件模块必须导出一个 Plugin 实例（当前版本只保留这一种写法）：

```python
from neobot_modloader import Plugin

plugin = Plugin("ping")
```

> 不再支持旧的 setup(ctx)、ctx.on.*、Matcher、on_command() 等兼容 API。

## 注册命令

```python
from neobot_modloader import Plugin, Reply

plugin = Plugin("ping")

@plugin.on.command("ping")
async def ping():
    return Reply("pong")
```

## 注册消息处理器

```python
@plugin.on.message("你好")
async def hello(message):
    return Reply("你好呀！")
```

支持消息模式（MessagePattern）与正则模式（RegexPattern）匹配。

## 注册工具（function-calling）

```python
@plugin.on.tool("get_weather", description="查询天气", parameters={...})
async def get_weather(city: str) -> str:
    return f"{city} 的天气是晴天"
```

工具以 OpenAI function-calling 形式注入给 LLM，名称自动加前缀。

## 注册子 Agent

```python
@plugin.on.agent("analyzer", description="数据分析 Agent")
async def analyzer(task: str) -> str:
    # 返回分析结果
    return f"分析结果: {task}"
```

## Markdown Skill

在插件包内创建 skills/<skill-name>/SKILL.md，modloader 会自动加载为 Markdown Skill（见 packages/modloader/example_plugins/full_plugin/skills/weather-guide/SKILL.md 示例）。

## 钩子（生命周期事件）

插件可订阅生命周期事件：

```python
@plugin.on.lifecycle("config.changed")
async def on_config_changed():
    ...
```

## 插件数据库

插件可携带数据库迁移（database_example 示例展示了 migrations.py + models.py 的用法），通过 PluginDatabase 访问。

## 配置模型

```python
from pydantic import BaseModel

class WeatherConfig(BaseModel):
    api_key: str = ""

plugin = Plugin("weather", config=WeatherConfig)
```

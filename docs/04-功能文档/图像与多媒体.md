# 图像与多媒体

NeoBot 支持图像识别、图像创作（生图/图库/表情包）、图片池与语音合成（TTS）。

## 图像识别

- 使用 `models.vision_model`（默认 Qwen/Qwen3-VL-8B-Instruct，硅基流动）分析图片内容
- 应用场景：用户发送图片时解析内容、头像分析、图片池分类
- 实现：[`app/src/neobot_app/image/parser.py`](../../app/src/neobot_app/image/parser.py)（ImageParseSkill）

## 图像创作（`agent.creator` 配置）

整体开关 `agent.creator.enabled`（默认 false）。包含三个子功能：

### 生图（Drawing）

- 模型：`models.creator_image_model`（默认 FLUX.1-schnell）
- **后台绘图**（`agent.creator.drawing.background_enabled`，默认 true）：绘图任务在后台执行，完成后通知主 Agent；关闭则回退同步阻塞模式
  - `cooldown_seconds`（默认 60）：同一管线绘图冷却
  - `notification_retry_seconds`（默认 30）+ `max_retries`（默认 1）：完成通知重试
  - `startup_grace_seconds`（默认 3.0）：启动宽限期
  - `max_tasks_per_pipeline`（默认 20）：每聊天流最大后台任务数
- 实现：`app/src/neobot_app/drawing/`（manager/service/tasks）

### 图库（Gallery）

- `agent.creator.gallery.capacity`（默认 10）：图库容量上限；0 禁用图库管理工具
- `page_size`（默认 50）：列表分页
- 图片保存于 `data/creator/gallery/`

### 表情包（Emoji）

- `agent.creator.emoji.allow_add` / `allow_delete`（默认 false）：是否允许 Creator Agent 增删表情包
- `page_size`（默认 50）：列表分页
- 实现：`app/src/neobot_app/emoji/`（service/mapping）

## 图片池（Image Pool）

- [`app/src/neobot_app/image_pool.py`](../../app/src/neobot_app/image_pool.py)：Bot 收集/管理图片的池子，供后续使用（如找图发送）
- 相关 Skill：ImagePoolSkill

## Markdown 渲染为图片

- 长回复（代码块/表格/公式）通过 `send_long_reply` 工具发送时，由 [`app/src/neobot_app/reply/markdown_image.py`](../../app/src/neobot_app/reply/markdown_image.py) 渲染为图片
- 依赖：markdown、pillowmd、fpdf2 等文档/图像库

## TTS 语音合成（`tts` 配置）

- 开关 `tts.enabled`（默认 true）
- 提供商 `tts_provider`：`siliconflow`（默认，CosyVoice2）或 `volcengine`（火山引擎）
- 模型 `models.tts_model`（默认 FunAudioLLM/CosyVoice2-0.5B）
- 输出：`response_format`（默认 mp3）、`output_dir`（默认 `./data/tts`）、流式生成 `stream`（默认 true，仅硅基流动）
- **参考音频**（仅硅基流动）：`reference_voice.enabled` 开启后可上传参考音频克隆音色；上传失败时可自动禁用 TTS（`disable_tts_on_upload_failure`）
- **火山引擎**（`huoshan` 段）：`speaker_id` 音色、`resource_id`（seed-icl-2.0/1.0 声音复刻、seed-tts-2.0/1.0 语音合成）、`model`、`format`、`sample_rate` 等
- 实现：[`app/src/neobot_app/audio/`](../../app/src/neobot_app/audio/)（[tts.py](../../app/src/neobot_app/audio/tts.py)、[volcengine_tts.py](../../app/src/neobot_app/audio/volcengine_tts.py)）

## 文件服务器（`file_server` 配置）

- 用于向 QQ 发送本地文件/图片时提供可访问 URL
- 实现：[app/src/neobot_app/core/file_server.py](../../app/src/neobot_app/core/file_server.py)

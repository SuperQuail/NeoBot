# 图像与多媒体

NeoBot 支持图像识别、图像创作（生图/图库/表情包）、图片池与语音合成（TTS）。

## 图像识别

- 使用 `models.vision_model`（默认 Qwen/Qwen3-VL-8B-Instruct，硅基流动）分析图片内容
- 应用场景：用户发送图片时解析内容、头像分析、图片池分类
- 实现：[`app/src/neobot_app/image/parser.py`](../../app/src/neobot_app/image/parser.py)（ImageParseSkill）

### 主推理模型原生视觉

在主回复路由所选模型上设置 `native_vision=true` 即可；回退路由固定使用 `models.vision_model`（无需手选回退模型）。配置示例见[配置参考](../05-配置参考.md)。默认关闭，保留原有独立视觉模型解析流程。

主模型不可用（创建失败）或无法处理图片时，自动切换到 `vision_model` 作为对话模型：图片仍随请求发送，回答可正常基于图片内容。

开启后：

- 聊天图片不再被自动提交给外部视觉模型、替换成文字描述，保留原始图片段供按需获取。
- 主 Agent 隐藏并拒绝执行 `image_parse__parse_image`、`drawing__inspect_image`、`user_profile__analyze_user_avatar`，改用普通工具 `image_context__add_image`。本地 YOLO 检测、图库管理、图片发送仍保留。
- 正文保留默认文本描述。`chat.native_vision_default_image_count` 控制自动加载数量，默认 **4 张**，`0` 关闭；Agent 模式从当前正文上下文选择最近图片（含回复引用）。默认图片和主动加载图片统一附在**每次请求提示词末尾**，逐张标注正文消息编号、真实消息 ID、图片序号或工具来源，不在正文中穿插图片。
- 图片载荷不放进工具返回 JSON，也不跨会话共享。主动 `image_context__add_image` **不设张数上限**，不受默认自动数量限制，也不会因默认数量而被淘汰；仍有单图及请求字节大小等安全限制。
- 基础 `common` 模式没有工具，按相同默认数量配置加载当前消息及回复引用的图片；需要按需检索图库或历史图片时使用默认的 `agent` 模式。

`image_context__add_image` 来源示例：

| 来源 | 参数示例 |
|---|---|
| 聊天图片 | `{"msg_number": 75, "image_index": 0}`；用户回复图片时使用**被回复消息**编号 |
| OneBot / 聊天流 | `{"message_id": 123}` / `{"chat_flow_id": "Group_123", "image_index": 0}` |
| 本地文件 / URL / base64 | `image_path` / `image_url` / `image_base64` |
| 自身图库 | `{"image_id": "g_xxx"}` / `{"gallery_id": 1}` / `{"source": "gallery:1"}` |
| 当前会话暂存池 / 表情包 | `{"pool_key": "图片key"}` / `{"source": "emoji:1"}` |
| 多张图片 | `sources`、`image_path_list`、`image_url_list` 或聊天来源 + `image_indices` |

每次只能选一种来源形式；主动批量加载不设张数上限，单图 10 MiB、单次合计 20 MiB、原始像素最多 2000 万，按实际内容校验图片。超长边缩到 4096 像素，动图只取首帧，工具结果提供处理后尺寸等元数据。主动加入的图片在当前管线中持续保留；供应商自身的请求大小、上下文和图片总数限制仍然适用。

**DeepSeek 兼容性：**按[官方图像理解文档](https://api-docs.deepseek.com/zh-cn/guides/vision)支持 `deepseek-v4-flash-vision-exp`，使用 Chat Completions 的 `user.content[]` + `image_url`；URL、本地文件及聊天图片经本地获取后使用 data URL 内联。支持 JPEG/PNG/GIF/WebP 输入（动图转换首帧），并兼容 OpenAI 格式服务及 Anthropic 的 `image.source` 转换。当前工具不使用 Files API 上传，也不新增 Responses API 端点。

**发送失败回退：**明确的“不支持图片”或不支持图片内容数组的接口错误会记录 ERROR，关闭运行时原生视觉能力，切换到配置的非视觉模型，移除请求中的图片并明确告知模型未看到图片；主 Agent 恢复独立视觉解析工具。错误图片、鉴权失败、限流和普通网络故障不会被误判为“不支持视觉”。若独立 `vision_model` 未配置，非视觉模型仍可回复文字，但无法代看图片；会明确返回解析服务不可用。回退路由无效或不可用时启动会报告配置错误，不会擅自选择其他模型。

## 图像创作（`agent.creator` 配置）

整体开关 `agent.creator.enabled`（默认 false）。包含三个子功能：

### 生图（Drawing）

- 模型：`models.creator_image_models`（列表，默认 FLUX.1-schnell；配置多个供应商时 `draw` 工具可用 `provider` 参数指定）
- **后台绘图**（`agent.creator.drawing.background_enabled`，默认 true）：绘图任务在后台执行，完成后通知主 Agent；关闭则回退同步阻塞模式
  - `cooldown_seconds`（默认 60）：同一管线绘图冷却
  - `notification_retry_seconds`（默认 30）+ `max_retries`（默认 1）：完成通知重试
  - `startup_grace_seconds`（默认 3.0）：启动宽限期
  - `max_tasks_per_pipeline`（默认 20）：每聊天流最大后台任务数
- 实现：`app/src/neobot_app/drawing/`（manager/service/tasks）

### 图库（Gallery）

- `agent.creator.gallery.capacity`（默认 10）：图库容量上限；0 禁用图库管理工具
- `page_size`（默认 50）：列表分页
- 图片保存于 `data/creator/gallery/`

### 表情包（Emoji）

- `agent.creator.emoji.allow_add` / `allow_delete`（默认 false）：是否允许 Creator Agent 增删表情包
- `page_size`（默认 50）：列表分页
- 实现：`app/src/neobot_app/emoji/`（service/mapping）

## 图片池（Image Pool）

- [`app/src/neobot_app/image_pool.py`](../../app/src/neobot_app/image_pool.py)：Bot 收集/管理图片的池子，供后续使用（如找图发送）
- 相关 Skill：ImagePoolSkill

## Markdown 渲染为图片

- 长回复（代码块/表格/公式）通过 `send_long_reply` 工具发送时，由 [`app/src/neobot_app/reply/markdown_image.py`](../../app/src/neobot_app/reply/markdown_image.py) 渲染为图片
- 依赖：markdown、pillowmd、fpdf2 等文档/图像库

## TTS 语音合成（`tts` 配置）

- 开关 `tts.enabled`（默认 true）
- 提供商 `tts_provider`：`siliconflow`（默认，CosyVoice2）或 `volcengine`（火山引擎）
- 模型 `models.tts_model`（默认 FunAudioLLM/CosyVoice2-0.5B）
- 输出：`response_format`（默认 mp3）、`output_dir`（默认 `./data/tts`）、流式生成 `stream`（默认 true，仅硅基流动）
- **参考音频**（仅硅基流动）：`reference_voice.enabled` 开启后可上传参考音频克隆音色；上传失败时可自动禁用 TTS（`disable_tts_on_upload_failure`）
- **火山引擎**（`huoshan` 段）：`speaker_id` 音色、`resource_id`（seed-icl-2.0/1.0 声音复刻、seed-tts-2.0/1.0 语音合成）、`model`、`format`、`sample_rate` 等
- 实现：[`app/src/neobot_app/audio/`](../../app/src/neobot_app/audio/)（[tts.py](../../app/src/neobot_app/audio/tts.py)、[volcengine_tts.py](../../app/src/neobot_app/audio/volcengine_tts.py)）

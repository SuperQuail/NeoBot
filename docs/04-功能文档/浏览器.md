# 浏览器

浏览器因启动模式或新环境要求而重启时，会使用重启后的 CDP 连接地址。连接失败后会回收该实例的初始化缓存，下次尝试重新建立连接，避免半初始化对象持续导致卡片截图失败。

自动下载的 Chromium 会跨启动复用。检测遵循 `PLAYWRIGHT_BROWSERS_PATH`；设为 `0` 时使用
当前 Python 环境内 Playwright 的 `driver/package/.local-browsers`。Linux 未设置该变量时
使用 `$XDG_CACHE_HOME/ms-playwright`，默认是 `~/.cache/ms-playwright`。相对缓存路径按
`INIT_CWD`（未设置时为当前工作目录）解析，应与执行安装命令时保持一致。

> B站提示：agent 用浏览器打开 B站页面（bilibili.com / b23.tv）时，工具结果会带警告——模拟浏览器操作不带B站cookie且可能触发风控，请不要使用浏览器操作来访问B站；请用 B站专用工具。

NeoBot 内置浏览器自动化能力，基于 **DrissionPage**（Chromium 控制）与 **Playwright**，让 Agent 能浏览网页、截图、读取网络请求、获取视频。

## 浏览器 Agent（`agent.browser` 配置）

- `enabled`（默认 true）：是否启用浏览器 Agent
- `hold_max_minutes`（默认 120）：页面保活最大分钟数
- `auto_close_idle_seconds`（默认 600）：空闲自动关闭秒数（10 分钟）
- `data_dir`（默认 `./data/browser/`）：浏览器用户数据目录
- `browser_path`：Chrome/Chromium 可执行路径，留空自动检测。优先复用已安装的 Playwright Chromium；Windows 系统浏览器按 Chrome > Edge > Chromium 选择。配置路径不存在或不可访问时会记录警告并回退自动检测。

## 相关 Skill

| Skill | 能力 |
|---|---|
| `browser` | 浏览器操作：导航、点击、输入、滚动、截图等 |
| `browser_network` | 网络请求拦截与读取（网页背后的 API 数据） |
| `browser_video` | 视频获取（解析网页中的视频地址） |

实现位于 `app/src/neobot_app/browser/` 与 `app/src/neobot_app/skills/browser_*.py`。

## 手动登录与会话复用

`neobot open_web [URL]` 命令启动**有头浏览器**供手动登录认证（默认打开 Bing）：

```bash
neobot open_web "https://example.com"
```

- 登录状态保存于 `data/browser/profiles/manual_login/`
- 后续无头浏览器自动复用该会话（Cookie），无需重复登录

## 生命周期管理

[`app/src/neobot_app/runtime/browser_lifecycle.py`](../../app/src/neobot_app/runtime/browser_lifecycle.py) 管理浏览器实例生命周期：页面保活、空闲自动关闭、截图尺寸校验（[`scripts/verify_browser_screenshot_size.py`](../../scripts/verify_browser_screenshot_size.py)）等。

## 常见场景

- 查询实时信息（天气、价格、新闻）并截图
- 读取网页源码/网络请求获取结构化数据
- 模拟登录后操作需要认证的网站
- 获取网页视频并发送

# 记忆系统

NeoBot 拥有多层记忆体系，从短期上下文到长期档案，让 Bot 能「记住」用户、群聊与共同经历。记忆服务位于 `packages/memory`，记忆相关配置位于 `agent.memory`。

## 记忆层级

| 层级 | 载体 | 说明 |
|---|---|---|
| 短期上下文 | 消息队列（[`message/queue.py`](../../app/src/neobot_app/message/queue.py)） | 当前聊天流内的消息，上限约 100 条 |
| 触发式记忆 | 记忆 Agent（`agent_model.memory`） | 按消息间隔自动触发，总结当前对话写入档案 |
| 档案记忆 | [`packages/memory/archive_service.py`](../../packages/memory/src/neobot_memory/archive_service.py) | 对用户/群/关键词的长期记忆条目，AI 自动总结与精简 |
| 用户画像 | [`user_profiles.py`](../../app/src/neobot_app/user_profiles.py) + [UserProfileSkill](./技能系统Skills.md) | 用户备注、性格印象，支持头像图片分析 |
| 好感度 | favorability | 数值化的关系亲密度（-1000 ~ 1000） |
| 自适应提示词 | AdaptivePromptSkill | Agent 可自主维护的永久记忆文本 |

## 触发式记忆

`agent.memory.trigger` 配置：

- `group_interval`（默认 500）：群聊每 N 条消息触发一次记忆处理；0 表示禁用
- `private_interval`（默认 200）：私聊每 N 条消息触发一次；0 表示禁用
- `prompt_snippet_chars`（默认 120）：总结提示词中每条消息的最大展示字符数，超出部分截断，
  模型用 `archive_crud__read_pending_messages` 按需读取全文；0 表示不截断
- `max_tool_rounds`（默认 20）：单次总结最多工具调用轮次，防止工具失败时反复重试烧 token

触发后由记忆 Agent 总结对话，写入用户/群档案（必要时同步写入物品/事件关键词档案）。

### 写入方式（增量优先，控制 token）

- 全量档案（`user_profile` / `group_profile`）：只用 `patch_archive` 增量写入
  （`op=append/prepend/replace/delete`），只提交改动片段，**不需要先读全文，也不重写整条档案**；
  需要修改既有内容时先用 `read_archive(mode='outline')` 定位、再按 `offset` 分页读该片段后定点修改。
- 定长摘要（`user_summary` / `group_summary`）：这是唯一允许用 `save_archive` 整条重写的档案，
  且仅在内容确实需要变化时重写，硬上限见 `archive.max_chars` / `archive.group_profile_max_chars`。
- 待总结消息按序号注入（`[序号] 发送者: 文本`），超长消息只注入片段；模型需要全文时
  调用 `archive_crud__read_pending_messages(conversation_key, indices)` 按需读取。
- 一次总结中所有工具调用都失败时，计数器会保留待下次重试，避免消息丢失。
- 总结调用的 token 用量按 `agent:memory` 记入用量统计，可在「统计与计费」中查看。

## 档案记忆（Archive）

档案是 Bot 对某个实体的长期记忆条目。相关配置 `agent.memory.archive`：

- `allow_delete`（默认 false）：是否允许 `delete_archive` 删除档案；关闭时该工具**不会注入给模型**，即使被调用也会被拒绝
- `allowed_tables`：允许访问的档案表名列表（留空不限制）；限制后 `save_archive` / `patch_archive` / `read_archive` / `list_archive` / `delete_archive` 都会校验表名（内部待总结消息表 `memory_counter` 不受限制）
- `auto_compact_chars`（默认 200）：单条档案超过此字符数时触发 AI 自动精简；0 禁用
  （当前代码未实现该自动精简，仅保留配置项）
- `max_chars`（默认 500）：个人记忆渲染进系统提示词的展示上限（超出由模型分页查阅）
- `group_profile_max_chars`（默认 1500）：群聊记忆渲染进系统提示词的展示上限（超出由模型分页查阅）

> 注意：`max_chars` / `group_profile_max_chars` 只限制**渲染进提示词**的长度，
> 档案本体不截断、可长期累积；写入请优先用 `patch_archive` 增量修改，避免整条重写。

档案按实体分为：

- **用户档案**（user_profile）：Bot 对某位用户的印象
- **群档案**（group_profile）：Bot 对某个群的印象
- **物品/事件关键词档案**（`agent.memory.item_archive`，默认表名 `item_archive`）：以关键词为键的独立数据表，记录对特定物品、事件、话题的长期信息；自动记忆总结系统会同步写入

## 用户画像与头像分析

- [UserProfileSkill](./技能系统Skills.md) 允许 Agent 查询/更新用户画像（[`app/src/neobot_app/user_profiles.py`](../../app/src/neobot_app/user_profiles.py)）
- 支持头像图片分析（视觉模型）：通过 `vision_model` 分析用户头像得出性格印象
- 周期性刷新：`enable_periodic_user_info_update`（默认 true）+ `user_info_update_interval_days`（默认 7 天）

## 好感度（Favorability）

- 每次档案总结时可变更好感度，单次上限 `max_change_per_summary`（默认 ±5）
- 范围 `min_value` ~ `max_value`（默认 -1000 ~ 1000）
- Agent 可通过 FavorabilitySkill 查询；好感度影响 Bot 的互动倾向（体现在提示词中）

## 自适应提示词（Adaptive Prompt）

- `agent.memory.adaptive_prompt_enabled`（默认 true）：Agent 可自主维护一段「永久记忆」文本
- `adaptive_prompt_max_chars`（默认 200）：超出自动截断
- 实现：`AdaptivePromptSkill`，Agent 通过工具读写，内容每次注入系统提示词

## 档案获取窗口

`chat.archive_fetch_window`（默认 20）：群成员列表窗口，只列出消息队列中最新的 N 条消息的发送者。

## 提示词中的档案注入

- **群聊**：默认只注入群档案（`group_summary` 优先、缺失时 `group_profile`，超长截断+引导）。
  群员档案默认**不注入**（`chat.inject_member_archives=false`），成员列表只保留昵称/QQ/好感度/印象等轻量信息，
  并附上按需读取引导：agent 需要某位群友的记忆时用
  `archive_crud__read_archive`（`user_summary` 优先、`user_profile` 回退，key=QQ号）按需读取。
  设为 `true` 可恢复旧行为（注入窗口内群员的个人档案）。
- **私聊**：注入对方的个人档案，超长时截取开头部分（`archive.max_chars`）并附分页/大纲按需读取引导。

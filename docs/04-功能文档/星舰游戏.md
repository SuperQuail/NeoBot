# 星舰游戏（官方插件 starship）

把网页面板的控制台功能搬进一艘可自由探索的 3D 科幻战舰：three.js 第一人称、
MC 式操作、舱室即菜单、舰外是实时渲染的太空。

- 插件目录：`app/src/neobot_app/builtin_plugins/starship/`
- 访问路径：`http://<面板地址>/game/`（与面板**共用端口**，侧栏「星舰」入口进入）
- 前置插件：`dashboard>=1.0.0`（面板不可用时本插件自动禁用，不影响 NeoBot 启动）

## 操作

| 按键 | 作用 |
| --- | --- |
| WASD | 移动 |
| 鼠标 | 视角（进入游戏后自动请求指针锁定） |
| 空格 | 跳跃 |
| Shift | 潜行（降低身高与速度） |
| Ctrl | 疾跑 |
| E | 与全息终端交互 / 离开终端 |
| F | 就座 / 起身 |
| M / Esc | 菜单（画质、灵敏度、返回控制台） |

舰内有三层甲板，靠爬梯上下（走进梯井按 W/S 上下）。

## 控制台面板在舰内的位置

| 面板菜单 | 舰内终端 | 位置 |
| --- | --- | --- |
| 仪表盘 | 主控台 | 舰桥（含待机 / 恢复运行 / 软重启 / 重启进程） |
| 机器人 | 通讯台 | 舰桥 |
| — | 星图导航台 | 舰桥（手动触发跃迁） |
| 插件管理 | 模块机架 | 工程舱（启停 / 热重载，显示依赖与自动禁用原因） |
| 系统状态 | 反应堆监控 | 工程舱 |
| 用量统计 | 能量分配 | 工程舱 |
| 提示词分析 | 神经矩阵 | 科学舱 |
| 日志 | 航行日志 | 档案舱 |
| 配置管理 | 舰载系统配置 | 指挥室（点参数行改值并保存 / 重载配置） |
| — | 战绩墙 | 货舱（小游戏排行榜与成就） |

小游戏站点：机库「炮塔模拟器」、工程舱「损管终端」、观景廊「舷侧炮塔」。

## 未启用面板在游戏内的表现

终端的可用性由真实的运行状态决定（`/game/api/status` → 面板的待机状态、
OneBot 连接、管理权限）：

- **待机（低功耗）**：用量 / 分析 / 通讯三个终端**熄屏下线**，屏幕变成琥珀色的
  「终端已下线」+ 原因 + 恢复指引；主控台、插件、配置、日志、系统终端仍可用，
  其中主控台可以一键「恢复运行」；
- **只读会话**（`dashboard.manage_plugins=false` 或远程管理关闭）：插件 / 配置终端
  标记为只读，写操作按钮禁用；
- **OneBot 未连接**：通讯台顶部给出「数据可能不是最新的」提示，但仍可查看历史数据。

## 舰外太空

- 程序化星空 / 星云天空盒（自定义 shader，无外部贴图）、行星与卫星、太阳；
- 小行星流（InstancedMesh，随机漂移与回收）、过往飞船沿航线穿过；
- **跃迁**：星图导航台手动触发，或按配置间隔自动触发；跃迁期间全屏星流、
  抵达新星系后星云配色、行星位置与航道全部重新生成。

## 小游戏

| 玩法 | 模式 | 说明 |
| --- | --- | --- |
| 舱外炮塔 `turret` | world | 接管相机与指针锁，击碎接近的小行星，舰体完整度归零即失败 |
| 损管抢修 `repair` | screen | 在全息屏上旋转导线，把电力从堆芯接到各系统，限时三轮 |

成绩提交到插件独立数据库（`plugins_data/starship/databases/starship.db`），
服务端按 `minigames.py` 里的规则校验分数上限；成就同样落库。

扩展新玩法见 `starship/frontend/README.md`。

## 性能与零开销

- **不进入游戏就没有额外开销**：服务端只是一个 HTTP 扩展点，没有任何后台任务；
  页面本身也不加载（静态资源按需请求）；
- 页面隐藏时停止渲染循环；
- 只有被聚焦的终端才轮询控制台接口，其余终端按画质档位低频刷新或完全静止；
- 画质三档（节能 / 标准 / 高画质）控制像素比、小行星与粒子数量、视距，
  以及未聚焦终端是否刷新；
- 舰体几何按材质合并成少量 draw call，小行星用 InstancedMesh。

## 构建

前端源码在 `starship/frontend/`，产物 `starship/web/` **随包分发**：

```bash
cd app/src/neobot_app/builtin_plugins/starship/frontend
pnpm install
pnpm build
```

`app/pyproject.toml` 里把 `frontend/**` 排除出源码包，只保留 `web/`，
因此部署 NeoBot 不需要 Node 或前端工具链。

## 配置

面板「插件 → starship → 配置」可在线编辑 `plugins_data/starship/config.toml`：

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `route` | `game` | 挂载路径（面板根下的单段路径） |
| `title` | `NeoBot 星舰` | 侧栏与引导页显示的名字 |
| `show_in_sidebar` | `true` | 是否在面板侧栏显示入口 |
| `default_quality` | `medium` | 默认画质（玩家可在游戏内覆盖，存浏览器本地） |
| `allow_minigames` | `true` | 是否允许进入小游戏 |
| `leaderboard_size` | `20` | 排行榜默认返回条数 |
| `jump_interval_minutes` | `6` | 自动跃迁间隔（0 = 关闭） |
| `enable_audio` | `true` | WebAudio 合成音效 |

配置改动需要重载插件生效（`config_hot_reload = false`）；插件本体支持热重载。

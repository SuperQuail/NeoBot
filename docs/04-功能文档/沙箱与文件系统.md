# 沙箱与文件系统

NeoBot 为 Agent 的文件操作提供**沙箱**：Agent 只能在其工作目录内读写文件，配合容量限制、临时文件清理与 SSRF 防护，控制 Agent 行为的风险面。

## 沙箱（`agent.sandbox` 配置）

```toml
[agent.sandbox]
enabled = true
max_total_size_bytes = 2147483648   # 沙箱总容量上限（默认 2GB），写入前检查，超出拒绝
temp_max_age_seconds = 1800         # 临时文件最大存活秒数（30 分钟）
temp_hold_max_minutes = 120         # 临时文件保活最大分钟数（2 小时）
scan_interval_seconds = 300         # 临时文件清理扫描间隔（5 分钟）
allowed_read_dirs = ["./data/emoji/", "./data/creator/gallery/"]  # 文件操作 Agent 可只读访问的目录
```

### 持久化文件定时维护（`agent.sandbox.maintenance`）

- `enabled`（默认 true）+ `interval_seconds`（默认 10800，3 小时）：定期维护沙箱持久化文件
- **调度以数据库记录为准**：每次维护（含跳过）都写入 `maintenance_runs` 表
  （`started_at / finished_at / status / trigger / tool_calls / summary / error / skipped_reason`）。
  进程启动时按「距上次成功维护是否已到 `interval_seconds`」判断：
  - 未到期 → 跳过并记录一条 `skipped`（含原因），不调用模型；
  - 上次状态是 `failed` 或 `running`（进程被中断）→ 立即补跑一次；
  - 到期 → 正常执行。
  这样重启进程不再无条件触发一次沙箱维护（此前每次重启都会在 60 秒后跑一整轮，
  生产实测两次重启各触发一次无意义维护）。

## 文件操作 Agent（`agent.file_operation`）

- `enabled`（默认 true）：是否启用文件操作 Agent
- `agent.system.allowed_work_dirs`（默认 `["./Data/"]`）：System Agent 允许操作的工作目录

文件操作 Agent 负责按主 Agent 的指示在沙箱内读写文件、处理文档（依赖 pypdf、python-docx、openpyxl、xlsxwriter、pikepdf 等）。

## SSRF 防护

[`app/src/neobot_app/utils/ssrf.py`](../../app/src/neobot_app/utils/ssrf.py) 提供 SSRF（服务端请求伪造）防护，用于浏览器/网络请求相关功能，防止 Agent 请求内网地址。

## 安全设计要点

1. **路径限制**：所有文件操作必须落在沙箱根目录内
2. **容量上限**：写入前检查总容量，超出拒绝（默认 2GB）
3. **临时文件自清理**：过期自动删除（30 分钟/2 小时）
4. **只读目录白名单**：`allowed_read_dirs` 控制 Agent 可读取的系统目录
5. **并发锁**：沙箱操作串行化，避免竞态

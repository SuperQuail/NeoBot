# 聊天与回复

NeoBot 的核心能力：在群聊与私聊中自然对话。本节说明消息如何进入队列、Bot 如何决定是否回复以及如何组织回复。

## 消息通道

- **群聊通道**与**私聊通道**各自维护独立的消息队列（[`app/src/neobot_app/message/queue.py`](../../app/src/neobot_app/message/queue.py)），队列长度上限为 `chat.max_group_chat_observations` / `chat.max_friend_chat_observations`（默认 100）。
- 启动时可选预热历史消息（`enable_group_startup_history_warmup` / `enable_friend_startup_history_warmup`，配合白名单），让 Bot 启动后即有上下文。
- 事件进入队列时带权重：戳一戳按 `poke_weight`（默认 0.2）计，回应按 `reaction_weight` 计。

## 回复模式

`chat.reply_mode`（在 `EnhancedChat` 中）可选：

- `agent`（默认，推荐）：Agent 模式。主模型在提示词约束下自主判断是否回复，可调用工具、委托子 Agent，回复由 send_reply 工具发出。
- `common`：基础模式。仅触发基础回复功能，通过概率系数决定是否回复，不推荐。

## 回复意愿（Willing）

Bot 并非每条消息都回复，回复与否由意愿服务（`app/src/neobot_app/willing/`）决定：

- `group_chat_chance`：群聊基础回复概率（默认 0.5）
- `willing_global_coefficient`（common 模式）/ `willing_agent_global_coefficient`（agent 模式）：全局回复概率系数
- `group_response_coefficient`：按群号配置的回复系数
- 名单控制：`group_use_black_list` / `friend_use_black_list` 选择黑名单或白名单模式，`group_list` / `friend_list` 为名单
- `reply_blacklist`：回复黑名单（QQ 号），名单内用户 @Bot 时不强制追加回复要求

## @ 与必回

- `at_mention_guaranteed_reply`（默认 true）：@ 时必回。
- `at_mention_reply_delay_seconds`（默认 5.0）：@ 提及时的回复延迟，期间收集后续群消息再生成回复，避免碎片化回复。

## 回复组织与后处理

- **短句切分**：回复会被自动切分为多条短句逐条发送（模拟打字间隔），`reply_sentence_cooldown_seconds` / `private_chat_sentence_cooldown_seconds` 控制逐句冷却（默认 2 秒）。
- **冷却**：`reply_cooldown_seconds` 控制距上次回复结束的最小间隔。
- **长回复保护**：`long_reply_max_length`（默认 300 字符）与 `long_reply_max_sentence_count`（默认 12 条）超限时触发 fallback（`long_reply_fallback_template`）；`enable_ai_reply_regenerate_on_length_limit`（默认 true）时先让 AI 重新生成更简短的版本。
- **AI 回复检查**：`ai_reply_check`（全量）或 `ai_reply_check_lightweight`（仅在过长/过多拦截时）开启后，send_reply 先返回切分结果供主 Agent 确认。
- **Markdown 长回复**：如需发送代码块/表格/公式等，使用 `send_long_reply` 工具，内容会渲染为图片发送（[`app/src/neobot_app/reply/markdown_image.py`](../../app/src/neobot_app/reply/markdown_image.py)）。
- **位置追踪**：`enable_last_reply_tracking` 记录「上次回复到」的位置并在提示词中显示，避免重复回复。

## 关键词规则

`chat.key_word` 配置关键词规则列表（`KeyWordRule`）：

```toml
[[chat.key_word]]
enabled = true
keywords = ["妈妈", "妈"]
prompt_list = ["你可以反问对方是不是叫夏亚"]
ignore_case = true
match_mode = "any"   # any / all
min_depth = -1
max_depth = 0
description = ""
```

命中关键词时，将 `prompt_list` 中的提示注入提示词，引导 Bot 做出特定反应（彩蛋/梗）。

## 随机表情包

`random_sticker_probability`（默认 0.1）：回复事件中随机触发聊天互动 Agent 发送表情包的概率。

## 相关配置

- 提示词模板：`chat.group_prompt_template` / `chat.friend_prompt_template`（含大量占位符：`{bot_name}`、`{current_time}`、`{message_list}`、`{memory_list}` 等）。非开发者不建议修改。
- 群聊/私聊描述：`chat.group_description` / `chat.friend_description`，用于让 Bot 了解群/好友背景。

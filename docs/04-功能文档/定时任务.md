# 定时任务

NeoBot 内置定时任务系统，让 Bot 能在指定时间主动执行任务（提醒、汇报、周期任务）。任务由 Agent 通过工具自助创建。

## 配置（`scheduled_task` 段）

```toml
[scheduled_task]
enabled = true                      # 是否启用定时任务系统；关闭后定时任务 Agent 不注册
reminder_cooldown_seconds = 300     # 同一定时任务在触发时间窗口内重复提醒的冷却秒数
poll_interval_seconds = 10          # 任务扫描间隔秒数
default_window_seconds = 3600       # 任务未指定时间窗口时的默认窗口秒数
max_repeating_tasks = 15            # 重复定时任务数量上限（一次性任务不计入）
default_one_shot_notification = true # 新建任务默认使用一次性通知
```

## 任务类型

- **一次性任务（once）**：在指定时间执行一次
- **重复任务（repeating）**：周期性执行，有数量上限（`max_repeating_tasks`）
- **时间窗口**：每个任务有触发时间窗口，窗口内触发通知
- **一次性通知**：每个触发窗口只通知一次并自动完成该窗口（不等同于 once 任务）

## 工作方式

1. **创建**：主 Agent 通过定时任务工具（ScheduledTaskSkill / 定时任务 Agent）创建任务，指定时间、窗口、内容
2. **扫描**：[`runtime/scheduled_tasks.py`](../../app/src/neobot_app/runtime/scheduled_tasks.py) 按 `poll_interval_seconds` 扫描到期任务
3. **触发**：到期后通过通知系统通知主 Agent（或直接执行任务内容）
4. **提醒冷却**：同一任务在窗口内重复提醒受 `reminder_cooldown_seconds` 限制

## 数据模型

[`packages/contracts/src/neobot_contracts/models/scheduled_task.py`](../../packages/contracts/src/neobot_contracts/models/scheduled_task.py) 定义任务模型；存储于数据库（`packages/storage` 的 Alembic 迁移 [`0012_add_scheduled_tasks.py`](../../packages/storage/src/neobot_storage/alembic/versions/0012_add_scheduled_tasks.py)）。

## 相关 Skill

- `reminder`：提醒 Skill（用户要求「几点提醒我」时使用）
- `background_trigger`：后台触发（延迟执行）
- 定时任务 Agent（`agent_model.scheduled_task` 路由编号）

# 搜索与网页解析

NeoBot 提供联网搜索与网页内容解析能力，让 Agent 能获取实时信息。

## 联网搜索（`web_search` 配置）

整体开关 `web_search.enabled`（默认 true）；关闭后搜索工具不会注册。

```toml
[web_search]
enabled = true
preview_pages_limit = 30   # 单次搜索返回结果总数上限（含主查询+所有变体）
max_search_rounds = 5      # 单次会话最多搜索轮次
variant_result_limit = 6   # 研究模式中每个变体查询返回的最大结果数

# 引擎与回退（fix(9)）。duckduckgo 始终作为最后兜底执行，排在浏览器通道之后。
engines = ["bing", "duckduckgo"]
browser_fallback = true          # HTTP 都失败后是否用浏览器脚本化通道补救
browser_timeout_seconds = 8.0    # 浏览器通道单次预算（实测单次约 1s，冷启动约 1.2s）
# engine_timeout_seconds = { duckduckgo = 15 }   # 按引擎覆盖单级预算（DDG 默认 15s）
```

### 检索与回退链路

一次搜索按「先换身份、再换站点」的顺序推进，**每一级都要过同一套质量闸门**（URL 归一化 +
C1 结构 / C3 相关性校验），判失败就把失败分级写进 `signals.failure`：

| 顺序 | 通道 | 预算 | 触发条件 | 失败分类与处置 |
|---|---|---|---|---|
| ① | Bing HTTP（会话化） | 12s | 总是先跑 | **结构类**（半包/乱码/解析不到）→ 同通道快重试 1 次；**网络类**（超时/挑战页）→ 直接下一级；**内容类**（错配页）→ 直接下一级 |
| ② | 浏览器脚本化通道 | 8s | ① 判失败且 `browser_fallback=true` | 复用进程内 Chromium 会话（冷启动 ~1.2s、复用后 ~1s/次），真实指纹 → 内容类失败的真正补救；未安装 Chromium 时自动跳过 |
| ③ | DuckDuckGo | 15s | ①② 都失败 | 最后兜底；判据放宽（不做 C3），结果标注 `degraded` |
| — | 空结果 | — | 页面明说「没有相关结果」 | **短路**：不再回退，返回 `degraded` + 空结果（不是故障） |

每次搜索会记录逐级明细到响应的 `signals.stages`（`stage` / `kind` / `ms` / `results`），
面板/日志可据此看出「这次结果是哪一级拿到的」。

> 为什么不是「换通道」而是「换身份」：实测错配页在 HTML 与 RSS 两条 HTTP 通道里给出**同一份
> 错误缓存**，换站点（DDG）又慢；换浏览器等于换指纹与会话，实测 12/12 可拿到真实结果。

实现位于 `app/src/neobot_app/web_search/`：

- [engine.py](../../app/src/neobot_app/web_search/engine.py)：搜索引擎适配（Bing、DuckDuckGo 等）
- [manager.py](../../app/src/neobot_app/web_search/manager.py)：回退链路编排（HTTP → 浏览器 → DDG）与逐级预算
- [browser_channel.py](../../app/src/neobot_app/web_search/browser_channel.py)：浏览器脚本化检索通道（会话复用）
- [urls.py](../../app/src/neobot_app/web_search/urls.py)：URL 归一化（解追踪壳、去跟踪参数、去重键）
- [validate.py](../../app/src/neobot_app/web_search/validate.py)：结果有效性校验与**失败分级**
- [session.py](../../app/src/neobot_app/web_search/session.py)：单次搜索会话（多轮查询）
- [models.py](../../app/src/neobot_app/web_search/models.py)：搜索结果数据模型

### 研究模式（多查询变体）

搜索工具支持研究模式：将主查询拆分为多个变体查询并行搜索，汇总结果（`variant_result_limit` 控制每变体返回数）。适用于需要全面信息的场景。

## 网页解析（`app/src/neobot_app/web_parser/`）

- [extractor.py](../../app/src/neobot_app/web_parser/extractor.py)：网页内容提取
- [structurer.py](../../app/src/neobot_app/web_parser/structurer.py)：内容结构化（标题/正文/列表等）
- [renderer.py](../../app/src/neobot_app/web_parser/renderer.py)：渲染为 Markdown，供 Agent 阅读

典型流程：搜索 → 打开链接 → 提取正文 → 渲染 Markdown → 注入 Agent 上下文。

## 相关 Skill

- 搜索相关工具通过 `web_search` 工具包注册（见 [`app/src/neobot_app/web_search_package.py`](../../app/src/neobot_app/web_search_package.py)）
- 网页解析可与浏览器 Skill 配合（复杂页面走浏览器，简单页面走解析器）

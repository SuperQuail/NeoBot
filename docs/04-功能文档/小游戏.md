# 小游戏（官方插件 minigame）

NeoBot 官方小游戏插件：**漂流瓶 / 成语接龙 / 签到与积分 / 抽签**四个玩法。

- 插件目录：`app/src/neobot_app/builtin_plugins/minigame/`
- 数据目录：`plugins_data/minigame/`（独立 SQLite 库 `databases/minigame.db`）
- 依赖：**无**（命令型玩法不需要网页面板，面板缺失时照常可用）
- 头像：统一取自本体头像存储，插件**不自行联网**；取不到时用首字母色块兜底

## 设计取向：程序只做「必须由程序做」的事

| 由程序负责 | 交给 AI 负责 |
| --- | --- |
| 随机结果（签到积分、抽签档位、接龙目标条数） | 怎么说出口、怎么追问、怎么安慰 |
| 每日上限、步数与时限护栏 | 这算不算成语、接不接得上、是否重复 |
| 计分记账、落库、池上限与随机转档 | 用户到底想玩什么、要不要先确认 |
| 卡片渲染与头像 | 判定通过后由 AI 决定是否提交计分 |

因此每个玩法都有**两条入口**：命令入口（确定性）与 agent 工具入口（交互）。

## 两条入口

### 命令面

| 命令 | 作用 | 输出 |
| --- | --- | --- |
| `/mg`（别名 `/游戏`） | 列出可用玩法与其它命令 | 菜单文本（确定性） |
| `/mg <游戏> [参数]` | 执行某个玩法 | 见各玩法（游戏结果卡片图，或交 AI 回复） |
| `/mg 瓶 ...` | 漂流瓶：`丢 <正文>` / `匿名 <正文>` / `捞` / `帮助` | 卡片图或 AI 回复 |
| `/mg 成语接龙` | 开始一局（程序随机目标条数） | 卡片图 + 交 AI 开场 |
| `/mg 签到` | 每日签到 | 卡片图 + 交 AI 组织文案 |
| `/mg 抽签` | 抽今日运势（当天已抽则重发同一结果） | 卡片图 + 交 AI 组织文案 |
| `/mg rank [页码]` | 积分排行榜（全局榜 + 本群榜） | 文本（确定性） |
| `/mg 积分` | 查看自己的积分与连续签到天数 | 文本（确定性） |
| `/mg help <游戏>` | 查看某个玩法的完整规则 | 文本（确定性） |
| `/mg stop` | 结束当前会话进行中的一局（发起者或次级管理员） | 文本（确定性） |

### agent 工具面

工具最终名是 `{插件名}__{工具名}`，即上表对应的：

| 工具 | 参数 | 作用 |
| --- | --- | --- |
| `minigame__bottle_write` | `content`、`anonymous` | 丢一个漂流瓶（正文 / 是否匿名） |
| `minigame__bottle_pick` | — | 随机捞一个漂流瓶 |
| `minigame__checkin` | — | 每日签到 |
| `minigame__fortune` | — | 抽今日运势（幂等） |
| `minigame__points` | — | 查看积分与连续签到天数（**只读**） |
| `minigame__help` | `game` | 查看某个玩法的规则 |
| `minigame__chengyu_submit` | `word` | 成语接龙记一步（不校验内容） |

- 工具还可以传**可选**的 `user_id` / `user_name`：不传时用「最近一次交互」的用户
  （命令或关键词入口会记录），传了就以此为准。
- 每个玩法的完整说明（给模型看的）同时挂在对应的技能包上，可用
  `skills__view_instructions` 查看。

### 意图入口（关键词）

直接对机器人说这些话即可进入 agent 交互路径（**不会直接执行游戏动作**）：

| 关键词 | 玩法 |
| --- | --- |
| 漂流瓶 / 丢瓶子 / 捞瓶子 | 漂流瓶 |
| 成语接龙 / 接龙 | 成语接龙 |
| 签到 / 打卡 | 签到 |
| 抽签 / 今日运势 / 运势 | 抽签 |

命中后插件会把「事实 + 引导」交给主回复管线，并**按玩法预激活**该玩法的工具，
于是模型在本轮回复里就能直接调用它们。引导块写明两种处理方式：

1. 用户只是顺口提到 / 想玩但没说清（例如「想玩漂流瓶」）→ **先询问确认**，不要直接执行；
2. 用户已经给出明确诉求、只是不是命令格式（例如「帮我匿名丢一个瓶子：今天也要开心」）
   → **直接调用对应工具执行**，再用自然语言回报结果。

未命中关键词时插件**完全不动**（不拦截、不消费、不预激活）。

这些玩法关键词还会随插件加载**登记进本体**：被 @ 的正文命中时，本体**跳过 @ 提及的
收集等待**（`chat.at_mention_reply_delay_seconds`）直接触发回复事件，少等几秒。
只登记**已启用玩法**的关键词，插件停用 / 卸载时随之注销。

## 什么时候程序直接做，什么时候交给 AI

| 情形 | 处理 |
| --- | --- |
| 纯工具命令（`/mg`、`/mg 积分`、`/mg rank`、`/mg help`） | 程序直接回确定性文本 |
| 参数完全正确的显式玩法命令（如 `/mg 瓶 丢 正文`） | 程序执行 + 渲染结果卡片图 |
| 签到、抽签 | 程序做随机与落库 + 出图，**文案由 AI 生成** |
| 格式错、缺参数、自然语言意图 | 走 agent 交互路径（程序只给事实与提示） |

卡片渲染不可用时（例如没装 chromium）自动降级为**信息等价**的纯文本，
用户始终有反馈，命令不报错。

## 卡片与主题

卡片是运行时把「HTML + CSS」交给本机 Chromium 渲染成 PNG 的，**没有构建步骤**：
部署侧只要有可用的 Chromium，就能出图；渲染不可用时一律降级为信息等价的纯文本。

### 主题模式

| 配置 | 含义 |
| --- | --- |
| `theme_mode = "random"`（默认） | 每张卡片从**该玩法的候选主题池**里随机挑一个主题 |
| `theme_mode = "fixed"` + `theme = "<主题名>"` | 所有卡片固定用这一个主题 |
| `theme_mode = "fixed"` + `theme = ""` | 各玩法用**自己的默认主题**（候选池里的第一个） |

每个玩法都有自己的候选池（默认主题在后括号里）：

| 玩法 | 候选主题池（默认主题） |
| --- | --- |
| 漂流瓶 | `bottle`（默认）、`minecraft` |
| 成语接龙 | `chengyu`（默认）、`minecraft` |
| 签到 | `checkin`（默认）、`minecraft` |
| 抽签 | `fortune`（默认）、`minecraft` |

- 主题名写错（或模式写错）会在加载配置时**直接报错**，不会静默回落；
- 抽签当天重复请求是「重发同一张图」，**连主题也是同一个**，不会换风格；
- 每次出图都会往日志写一行「小游戏卡片主题：玩法 X，模式 Y，本次使用 Z」，方便排查。

### Minecraft 主题

`minecraft` 是插件注册的像素主题，四个玩法都能用：

- 背景是**自己画的像素泥土平铺图**（16×16 整数像素，含亮暗噪点），叠一层压暗渐变，顶部一条草皮、右下角石块；
- 卡片边框是 3D 凸起：左上亮、右下暗，圆角为 0，面板与指标块同样带斜面；
- 标题是像素硬投影（`3px 3px 0`），强调色是草绿（`#7cc576`），标题右侧是苦力怕脸徽章；
- 字体内嵌 **Monocraft**（拉丁像素字体，常规 + 粗体）与 **FusionPixel 8px**（简体中文像素字体），
  拉丁字形走 Monocraft、中文逐字形回退到 FusionPixel，两者都是 OFL-1.1（许可文件随字体一起放在
  `builtin_plugins/minigame/assets/fonts/`）；
- 字号一律取 8 的整数倍（16 / 24px），并关闭字体平滑，避免像素边缘被抗锯齿糊掉。

### 各玩法的专属美术

美术片段（波浪 / 卷轴 / 日历 / 竹签等）全部由插件自己用 SVG 画出来，**不含任何用户输入**，
通过卡片的插槽（slot）与标记（marker）注入；用户正文一律先 HTML 转义、再走 Markdown、最后做 URL 白名单清洗。

| 玩法 | 卡片美术 |
| --- | --- |
| 漂流瓶 | 顶部海面场景（白天：暖阳 + 浪花 + 沙滩；匿名：夜空 + 月牙 + 星点）；玻璃瓶带高光与瓶内纸条；头像放在玻璃舱窗里配署名；正文写在米色纸条上（装订边 + 折角 + 纸纹）。普通与匿名两种模式各有自己的配色 |
| 成语接龙 | 上下木轴的宣纸卷轴 + 毛笔与墨迹 + 朱砂「龙」印；下面是进度节点链（已接的节点填朱砂、当前节点加虚线圈）与「第 k/N 条」；再下面是本局词录与规则 |
| 签到 | 日历页（年·月 + 大号日期 + 星期 + 当月格阵，今天那一格标红）＋ 打卡印章（首次是朱红「签到」，重复签到变灰「已签」）＋ 连续天数点阵（14 格，超出用「另 +N 天」补足）；三块指标卡把「本次得分 / 连续奖励 / 当前总分」放大呈现 |
| 抽签 | 真竹签：竹青渐变签身 + 三道竹节 + 斜切签头（露出浅色截面）+ **竖向艺术体档位文字**；右侧斜靠签筒（露出三根签头），下方木签架；按档位换配色（大吉金 / 吉橙 / 中吉青 / 小吉绿 / 平灰 / 小凶紫 / 凶暗灰），签尾系朱红签绳与印章 |

> 抽签内置主题 `fortune` 自带的竹签与「大吉」印章底纹在本卡片内会隐藏：本卡片自己画的竹签更大更专属，
> 留着会出现「凶签上盖着大吉印」的矛盾。

## 漂流瓶

### 发瓶

| 模式 | 命令 | 别人看到的 |
| --- | --- | --- |
| 普通 | `/mg 瓶 丢 <正文>` | QQ 号 + 昵称 + 头像 |
| 匿名 | `/mg 瓶 匿名 <正文>` | **只有头像**，昵称位固定显示「神秘的人」，不显示 QQ 号 |

- 匿名**不会隐藏头像**，也不会隐藏瓶子内容；两种模式的发送次数**共用**同一个每日额度。
- 正文去空白后 **1-500 字**（可配置上限）；**纯链接**（分隔后每一段都是网址）会被拒绝；
  支持 **Markdown**（粗体 / 列表 / 代码块 / 引用），渲染前先做 HTML 转义，
  因此正文里的原始 HTML 只会变成字面文本；**不做敏感词过滤**。
- 发送时会尽量触达一次本体头像刷新（失败不影响发瓶）。

### 捞瓶

- `/mg 瓶 捞` 从**全局瓶池**（跨会话、跨群）随机取一个别人丢的瓶子；
- 会自动**排除自己**，以及**自己最近 3 次捞到过的发送者**；
- 如果因为排除而没得捞，会**回落成普通随机**（仍然排除自己）并在卡片里提示；
- 池子真的空了就交给 AI 说明（不会有固定文案）。

### 每日额度与冷却

- 发瓶 **5 次 / 日**、捞瓶 **5 次 / 日**，两者**分别计**；
- 捞瓶**没有冷却**，没到上限就能连着捞；
- 超限时不会写库，并把「今天的额度用完了」这件事交给 AI 说明。

### 池上限与归档（永不按时间转档）

- 池内「待捞」瓶子达到上限（默认 1000）时，**随机**挑一条既有待捞瓶转为归档；
- 转档**不按时间顺序**、**不物理删除**、字段完整保留，因此长期不动的瓶子不会自己消失；
- 捞走的瓶子同样只是**软删除**（记录谁在什么时候捞的），不回池，也不提供任何查询入口；
- **瓶子发出后不可查询、不可撤回**——发瓶回复与 `/mg 瓶 帮助` 都会按模式写明可见范围
  与这句话。

### 计分

- 发瓶 **+1**、捞瓶 **+1**，写入统一积分账户。

## 成语接龙

- 开始：`/mg 成语接龙`（或 `/mg 接龙`，或直接说「成语接龙」）——程序随机给出
  **目标条数 N（默认 3-10）**、单局最多步数与每条时限，并把这些交给 AI 开场；
- 判定**不做程序约束**：是否算成语、是否接得上、是否重复，全部由 AI 在交互中处理；
- 提交：AI 判定通过后调用 `minigame__chengyu_submit(word)`（工具**不校验内容**，
  任意字符串都接受），程序只记流水、计一步、+1 分，并返回进度（第 k/N 条）；
- 护栏：每条 **60 秒**、单局最多 **10 步**（都可配置）；用满步数或超时即结束本局；
- 同一会话一局，**群内多人可参与**，谁先提交谁得分；
- 达成目标 N **额外 +N**；超时或未达成**不扣分**；
- 结束一局：`/mg stop`（发起者或次级管理员），超时/用满步数由程序自动结束。

## 签到与积分

- `/mg 签到`（或说「签到」）每天一次；积分由**程序随机**（默认 1-10）；
- **连续签到每天附加 +1，上限 +5**；断签后连续天数归零；
- 同一自然日重复签到**不加分**，会把今天的既有结果告诉 AI 由它回应；
- **不提供补签**，也**不会主动提醒**签到（不存在任何定时或触发式提醒），只在用户明确说签到时触发；
- 签到后会出一张卡片图，文案由 AI 组织（程序不发固定文案）；
- 查询：`/mg 积分` 或工具 `minigame__points`；
- **积分本期只读**：不能消费、不能兑换、不解锁特权、不影响任何其它功能。

## 抽签（今日运势）

- `/mg 抽签`（或说「抽签」「今日运势」）每天一次，由**程序**随机并落库；
- 默认五档：**大吉 / 吉 / 中吉 / 小吉 / 平**；开启 `fortune_include_bad_luck` 后扩展为
  **七档**（加 小凶 / 凶）；档位权重写在插件常量里，只有「是否含凶兆」可配；
- 产出运势卡片图 + 文本描述；文本描述交给 AI，由 AI 自己组织语言回答；
- **当天已抽过不重抽**：再次请求只会读库重渲染**同一结果**并重发图；跨日才会重抽；
- 抽签**不附带积分**。

## 配置

配置文件：`plugins_data/minigame/config.toml`（打包默认值见插件的 `plugin.toml`）。

| 键 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled_games` | 全部四个 | 启用的玩法 id 列表（`bottle` / `chengyu` / `checkin` / `fortune`）；去掉某项即整体下线该玩法 |
| `bottle_pool_max` | `1000` | 待捞瓶池上限；达到上限时随机转档一条既有待捞瓶 |
| `bottle_content_max_chars` | `500` | 漂流瓶正文长度上限（去空白后 1 到该值） |
| `bottle_show_sender_id` | `true` | **[WIP · 尚未接线]** 普通（非匿名）卡片是否显示发送者 QQ 号；**当前不生效**，普通瓶一律显示 QQ 号。接线计划见 `TODO/待办事项.md`「WIP 与后续计划」 |
| `bottle_avatar_cache_days` | `7` | 头像缓存天数的展示提示（实际刷新策略由本体头像存储决定） |
| `checkin_score_min` | `1` | 每日签到随机积分下限 |
| `checkin_score_max` | `10` | 每日签到随机积分上限 |
| `checkin_streak_bonus` | `1` | 连续签到每天的附加积分 |
| `checkin_streak_bonus_cap` | `5` | 连续签到附加积分上限 |
| `chengyu_target_min` | `3` | 成语接龙目标条数下限 |
| `chengyu_target_max` | `10` | 成语接龙目标条数上限 |
| `chengyu_max_steps` | `10` | 单局最多步数（用满即结束本局） |
| `chengyu_step_timeout_seconds` | `60` | 每条提交的时限（秒） |
| `fortune_include_bad_luck` | `false` | 抽签是否包含凶兆档位（小凶 / 凶） |
| `record_keep_days` | `30` | 战绩流水（审计 / 本群榜）保留天数 |
| `theme_mode` | `random` | 卡片主题模式：`random` 按该玩法的候选池随机 / `fixed` 固定用 `theme` |
| `theme` | `""` | `fixed` 时使用的主题名（`minecraft` / `bottle` / `fortune` / `chengyu` / `checkin` / `game` / `default`）；留空表示各玩法用自己的默认主题 |

## 数据表（插件独立库）

| 表 | 关键列 | 用途 |
| --- | --- | --- |
| `mg_profile` | `user_id` / `score` / `best_score` / `plays` / `wins` | 统一积分与战绩 |
| `mg_bottle` | `sender_id` / `sender_name` / `sender_avatar` / `content` / `anonymous` / `created_at` / `picked_at` / `picked_by` / `status` | 瓶池与瓶档（同表：待捞 / 已捞 / 超限归档） |
| `mg_daily` | `user_id` + `game_id` + `day` / `plays` | 每日额度 |
| `mg_checkin` | `user_id` + `day` / `score` / `streak` | 签到与连续天数 |
| `mg_fortune` | `user_id` + `day` / `result_key` / `result_text` | 抽签结果（每日一次） |
| `mg_record` | `user_id` / `game_id` / `score` / `conversation_id` | 审计流水与排行榜 |

数据库随插件迁移（在插件数据目录内），不影响本体数据库，也不会随插件升级丢失。

## 停用与卸载

- 在面板停用本插件：`/mg`（及别名）、四个玩法的全部命令与 agent 工具、关键词入口
  一起消失；数据留在 `plugins_data/minigame/` 不动；
- 只想下线某个玩法：把它的 id 从 `enabled_games` 里去掉即可（其余玩法照常）；
- 与本体或其它插件的命令重名时，命令会自动变成 `minigame__<名字>`，
  `/help` 里显示 [来源: minigame]。

## 边界与已知取舍

- 不做积分消费 / 兑换 / 与好感度打通；
- 不做跨群赛季、段位；排行榜提供全局榜与本群榜；

## 3. 验收标准

1. `uv run ruff check .`（仅本次改动文件）通过。
2. `uv run pytest -m "not browser and not network and not slow and not llm"` 全绿。
3. 手工：启用插件 → 面板看到配置表单 → 开白名单 → 收到一次自动问候 → 次日档案尾部出现「[近期状态]」。
4. 关闭插件后：不记录消息、不产生模型调用、已有定时任务不再新建。

## 4. 风险与对策

| 风险 | 对策 |
|---|---|
| 成本失控 | 四个刹车 + `agent:relic` 记账 + 面板可查 |
| 数据膨胀 | 保留期、素材条数上限、单条截断 |
| 打扰用户 | 安静时段、待触发上限、去重 |
| 结论污染档案 | 独立 `relic_user_analysis` 表，只在注入时追加，不改档案正文 |
| 本体改动回归 | P1–P3 都是小改，独立 PR、独立测试 |

## 5. 明确不做

- 不新建通用后台 agent API / 延迟队列 / 限流器。
- 不做 relic 面板页面（自动表单够用）。
- 不做权威节日源、每用户时区、多实例分布式锁。
- 不把日程注入主提示词；不碰本体 `messages` 表。
- 不把 relic agent 注册进 `AgentRegistry`（不进 `agents__delegate`）。

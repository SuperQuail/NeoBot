# 数据模型与接口

> 模块 X-1 · 归属 跨模块 · 状态：设计稿（未实现）

全部表结构、工具、命令、agent 路由与记账项集中在这里，其它文档只写用法。

## 1. 本体库（`neobot.db`）

### 1.1 新表 `user_relations`（M-A）

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | INTEGER PK | 自增 |
| `subject_id` | TEXT NOT NULL | 关系主体 QQ / bot 账号 |
| `relation` | TEXT NOT NULL | 关系词 |
| `object_id` | TEXT NOT NULL DEFAULT '' | 对象 QQ，未知为空串 |
| `object_name` | TEXT NOT NULL DEFAULT '' | 对象名称，未知为空串 |
| `note` | TEXT | 补充 |
| `source` | TEXT NOT NULL DEFAULT 'agent' | `agent` / `admin` |
| `confidence` | INTEGER NOT NULL DEFAULT 50 | 0–100 |
| `created_at` / `updated_at` | DATETIME | 审计 |

- `UNIQUE(subject_id, relation, object_id, object_name)`
- `INDEX(subject_id)`、`INDEX(object_id)`、`INDEX(relation)`
- 迁移：`packages/storage/src/neobot_storage/alembic/versions/0032_add_user_relations.py`

### 1.2 既有表（不改结构，只读）

| 表 | 用途 |
|---|---|
| `group_data` | M-B 搜索（`group_name`/`profile`） |
| `archive_memories` | 用户档案、群档案（`user_profile`/`user_summary`） |
| `user_data` | 昵称、备注、好感度 |

> 本体的 `messages` 表**不动**：relic 不写、不读它。

## 3. Agent 路由

## 4. 工具

### 4.1 relic 插件工具（`@plugin.tool`）

| 工具名 | package | 说明 |
|---|---|---|
| `relic__read_monthly_plan` | `plan` | 读当前/指定月日程 |
| `relic__enable_companion` | `whitelist` | 当前用户加入 R-B |
| `relic__disable_companion` | `whitelist` | 退出 R-B |
| `relic__enable_perfection` | `whitelist` | 加入 R-C（同时开 R-B） |
| `relic__record_diary_material` | `diary` | 写素材 |
| `relic__list_diary_materials` | `diary` | 列素材（只 summary） |
| `relic__read_diary_material` | `diary` | 读素材正文与来源 |
| `relic__search_messages` | `diary` | 按用户/会话检索消息 |

### 4.1.1 后台 agent 的提交工具（只给内部 Agent，不注册给主 agent）

| 工具名 | 使用方 | 说明 |
|---|---|---|
| `submit_monthly_plan` | `relic_planner` | 提交月度计划（month / festivals / days / festival_tasks） |
| `submit_companion_tasks` | 陪伴分析 | 提交要建的定时任务（tasks / reason） |
| `no_action` | 陪伴分析 | 明确本轮不建任务（reason） |
| `submit_analysis` | 精益求精 | 提交结论正文（text） |
| `skip_analysis` | 精益求精 | 证据不足时放弃（reason） |

这些工具只存在于对应 Agent 的 `Toolset` 里（`neobot_chat.tools.toolset`），**不进** `@plugin.tool` 注册表，
模型侧的可用工具由 Toolset 定义，参数即契约。

工具包说明用 `plugin.tool_package(...)` 写，供 `skills__view_instructions` 查看。

### 4.2 本体工具

| 工具名 | 归属 | 说明 |
|---|---|---|
| `relation__save_relation` / `relation__list_relations` / `relation__delete_relation` | 新 skill | M-A |
| `group_management__search_groups` | 已有 skill 加工具 | M-B |

## 5. 命令与能力

| 类型 | 名称 | 权限 | 说明 |
|---|---|---|---|
| 命令 | `/relic status` | 0 | 查看自己的白名单状态与最近分析 |
| 命令 | `/relic on <QQ> [companion\|perfection]` | 1 | 加入白名单 |
| 命令 | `/relic off <QQ>` | 1 | 移出白名单 |
| 命令 | `/relic plan [YYYY-MM]` | 1 | 查看/重生成月度规划 |
| 能力 | `relic.status` | — | 供面板与其它插件读取计数 |

命令走宿主命令表（`@plugin.command(..., permission=...)`），重名时自动加 `relic__` 前缀。

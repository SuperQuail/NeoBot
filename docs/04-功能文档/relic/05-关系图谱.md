# 关系图谱

> 模块 M-A · 归属 **本体** · 状态：设计稿（未实现）

让 agent 能记住并查询「谁和谁是什么关系」：Bot 自己的部署者、部署者的亲人、群友之间的亲属与社交关系。
数据落本体库 `user_relations`，供主对话 agent 与记忆 agent 共用。

## 1. 目标与非目标

**目标**

1. 结构化存边：`subject --relation--> object`，支持正查、反查、按名称模糊。
2. Bot 自身也是一等公民：`subject = bot 账号` 时表示「Bot 记住的部署者/亲人」。
3. 主对话 agent 与记忆 agent 都能读写（工具同一套）。

**非目标**

- 不做图算法（路径、连通分量）；只做边表查询。
- 不自动推断关系（由 agent 判断后显式写入）。
- 不替代用户档案里的自由文本描述。

## 2. 数据模型

本体库新表 `user_relations`（`packages/storage/src/neobot_storage/models.py`）：

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | int PK | 自增 |
| `subject_id` | str | 关系主体（QQ 号，或 bot 账号） |
| `relation` | str | 关系词，如 `母亲`、`部署者`、`同事` |
| `object_id` | str | 关系对象 QQ 号；未知写空串 |
| `object_name` | str | 对象显示名；未知写空串 |
| `note` | text | 补充说明 |
| `source` | str | `agent` / `admin` |
| `confidence` | int | 0–100，agent 自评 |
| `created_at` / `updated_at` | datetime | 审计 |

约束：`UNIQUE(subject_id, relation, object_id, object_name)`——空串而非 NULL，避免 SQLite 下 NULL 不参与唯一约束。
索引：`(subject_id)`、`(object_id)`、`(relation)`。

迁移：`packages/storage/src/neobot_storage/alembic/versions/0032_add_user_relations.py`（当前最大 0031）。

## 3. 语义

- 方向：`subject --relation--> object`。反查即 `object_id = ?`。
- `object_id` 未知时可以只记名字（例如只知道「部署者的妈妈」没 QQ 号）。
- Bot 自身：用配置里的 bot 账号作为 `subject_id`，`relation="部署者"`、`object_id=管理员 QQ`。
- 不存「互为关系」的对称推导（父子/夫妻需要两条边），由 agent 写入时自己保证。

## 4. 工具（本体 SkillModule）

新增 `app/src/neobot_app/skills/relation_skill.py`，形如既有 `archive_crud`（`app/src/neobot_app/skills/archive_crud.py`）：

| 工具 | 参数 | 说明 |
|---|---|---|
| `relation__save_relation` | subject_id、relation、object_id?、object_name?、note?、confidence? | upsert，返回 `{id}` |
| `relation__list_relations` | subject_id?、object_id?、relation?、query?、limit(≤50) | 三向查询；`query` 对 `object_name`/`note`/`relation` 模糊 |
| `relation__delete_relation` | id | 需 `agent.memory.allow_delete`（与档案删除同一开关） |

返回统一 JSON，未知参数报错而不是静默忽略。

## 5. 接入点

1. `app/src/neobot_app/skills/__init__.py` 注册新 SkillModule（主 agent 可见，按需加载工具 schema）。
2. `app/src/neobot_app/bootstrap/_services.py:380-403` 的 `summary_tool_defs` 加一行，记忆 agent 才能用。
3. 提示词：在记忆 agent 的总结提示词（`app/src/neobot_app/runtime/archive_parts/summary_prompt.py`）加一句「发现人物关系时用 `relation__save_relation` 记录」。

## 6. 提示词注入（可选，默认关）

群成员渲染 `<群友_N>` 时，可附带一句关系摘要，例如「该用户是你的部署者的母亲」。
实现位置：`app/src/neobot_app/user_profiles.py:750-808`（`_format_group_member_line`）。

开关 `[agent.memory] relation_graph_inject`，**默认 false**：关系通常只在需要时查，常驻提示词会膨胀。

## 7. 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `agent.memory.relation_graph` | true | 工具是否注册 |
| `agent.memory.relation_graph_inject` | false | 是否把关系摘要写进群成员行 |
| `agent.memory.relation_graph_max_chars` | 120 | 注入时的字数上限 |

## 8. 失败与边界

- 唯一约束冲突：`save_relation` 走 upsert（更新 note/confidence），不报错给模型。
- 参数校验：`subject_id` 必须非空；`object_id` 与 `object_name` 不能同时为空。
- 隐私：关系是敏感信息，只在 agent 侧查询，不进面板列表（面板只显示条数）；不写 `note` 里的凭据。
- 量级：个人部署通常几百条边，无需分页优化；`list_relations` 的 limit 上限 50。

## 9. 测试与验收

- 单元：upsert 幂等、唯一约束、正查/反查/模糊查询。
- 单元：空 subject / 双空 object 报错。
- 集成：工具经 SkillManager 注册后，名字为 `relation__*`，且出现在记忆 agent 的工具表里。
- 迁移：升级/降级可重复执行。

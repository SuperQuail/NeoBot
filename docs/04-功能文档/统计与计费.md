# 统计与计费

NeoBot 跟踪 LLM 调用用量与费用，提供余额查询与费用报告，帮助控制运行成本。

## 用量统计（`app/src/neobot_app/statistics/`）

- `tracker.py`：模型用量记录（输入/输出 Token、缓存命中 Token）
- `reporter.py`：费用报告生成
- `balance.py`：余额检查（BalanceChecker）

## 模型计费配置（`models.*.pricing`）

每个模型注册项可配置：

```toml
[models.primary_chat_model.pricing]
input_price_per_mtokens = 0.0     # 输入价格（每百万 Token）
output_price_per_mtokens = 0.0    # 输出价格（每百万 Token）
cache_hit_price_per_mtokens = 0.0 # 缓存命中价格（每百万 Token）
billing_metric = ""               # 非 Token 计费模型的平台计费标识（如 TTS 按字符）
```

计费币种为 CNY（数据库迁移 `0018_rename_cost_usd_to_cny.py`）。

## 数据存储

- 模型用量记录表：数据库迁移 `0017_add_model_usage_records.py`
- 缓存命中 Token 字段：`0019_add_cache_hit_tokens_to_usage.py`

## 余额 Skill

- `balance` Skill（BalanceSkill）：Agent 可查询当前余额/费用情况
- 在费用敏感场景（如自修复 Agent 日限额）中用于防止费用失控

## 费用控制相关配置

- 自修复 Agent：`agent.self_healing.daily_limit`（默认每日 5 次）
- 后台绘图：`agent.creator.drawing.max_tasks_per_pipeline` 等任务上限
- 定时任务：`scheduled_task.max_repeating_tasks`（默认 15）

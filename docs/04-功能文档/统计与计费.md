# 统计与计费

NeoBot 跟踪 LLM 调用用量与费用，提供余额查询与费用报告，帮助控制运行成本。

## 用量统计（`app/src/neobot_app/statistics/`）

- [tracker.py](../../app/src/neobot_app/statistics/tracker.py)：模型用量记录（输入/输出 Token、缓存命中 Token）
- [reporter.py](../../app/src/neobot_app/statistics/reporter.py)：费用报告生成
- [balance.py](../../app/src/neobot_app/statistics/balance.py)：余额检查（BalanceChecker）

## 模型计费配置（`models.registry[].pricing`）

模型库中的每个模型可配置：

```toml
[[models.registry]]
key = "deepseek-v4-pro"
# … provider / model_name / settings …

[models.registry.pricing]
input_price_per_mtokens = 0.0     # 输入价格（每百万 Token）
output_price_per_mtokens = 0.0    # 输出价格（每百万 Token）
cache_hit_price_per_mtokens = 0.0 # 缓存命中价格（每百万 Token）
billing_metric = ""               # 非 Token 计费模型的平台计费标识（如 TTS 按字符）
```

计费币种为 CNY（数据库迁移 [`0018_rename_cost_usd_to_cny.py`](../../packages/storage/src/neobot_storage/alembic/versions/0018_rename_cost_usd_to_cny.py)）。

## 面板用量图表

网页面板的「用量统计」页读取 `GET /api/series/usage?hours=<小时数>&bucket=hour|day`：

- `points`：按小时/天分桶的金额（CNY）、输入/输出 Token、缓存命中 Token 与调用次数；
- `models` / `modules`：按「供应商 + 模型」与调用模块的金额排行（各取前 12）；
- `totals`：所选窗口内的合计值；数据库不可用时返回 `available = false`，页面显示空状态。

聚合在存储层用 SQL 完成（`SqlAlchemyUsageRepository.series_since` 等），面板不拉取原始记录。

## 余额 Skill

- `deepseek_balance` Skill（BalanceSkill，`name = "deepseek_balance"`）：Agent 可查询 DeepSeek 账户余额；仅在 `enable_balance_check` 开启且 DeepSeek 已配置时注册
- 在费用敏感场景（如自修复 Agent 日限额）中用于防止费用失控

## 费用控制相关配置

- 自修复 Agent：`agent.self_healing.daily_limit`（默认每日 5 次）
- 后台绘图：`agent.creator.drawing.max_tasks_per_pipeline` 等任务上限
- 定时任务：`scheduled_task.max_repeating_tasks`（默认 15）

# 网页面板

NeoBot 的网页面板是**官方内置插件 `dashboard`**（基于 aiohttp），随主进程启停。它取代了旧版的管理员控制台（9891）与调试控制台（9981），是当前唯一的网页面板。

- 插件位置：[app/src/neobot_app/builtin_plugins/dashboard/](../../app/src/neobot_app/builtin_plugins/dashboard/)
- 配置来源：本体 `data/config.toml` 的 `[dashboard]` 分区（**不是**插件自己的 `plugin.toml`）
- 前端：源码在插件目录 `frontend/`（React + Vite），构建产物 `web/` 随包分发，使用面板**不需要安装 Node.js**

## 启动与访问

- 默认**开启**（`dashboard.enabled = true`），监听 `0.0.0.0:9981`，即默认对网络开放
- 本机访问 `http://127.0.0.1:9981/`；跨机访问 `http://<服务器IP>:9981/`
- 端口被占用时，从 `dashboard.port` 起**最多向后尝试 10 个端口**；改用其它端口后会在启动日志打印告警，提示同步修改 `dashboard.port`
- 只在本机使用时可把 `host` 改为 `127.0.0.1`，收敛监听范围
- 可用 `base_path` 把面板挂在路径前缀下（如 `/neobot`），便于反向代理

## 登录（访问令牌）

面板没有密码，只有**访问令牌（Access Token）**：

1. 打开面板，在登录页粘贴访问令牌
2. 令牌来源优先级：
   - `config.toml` 的 `[dashboard].access_token`（非空时优先）
   - 数据目录 `plugins_data/dashboard/access_token.txt`（此前已生成时复用）
   - 两者都没有时自动生成并写入该文件（权限 0600），同时打印在启动日志里
3. 登录成功后使用 HttpOnly Cookie 保存会话（内存态，重启即失效）；写操作需要 CSRF 令牌，由前端自动携带
4. 登录失败按 IP 限速：在 `login_rate_limit_window_seconds` 窗口内失败超过 `login_max_failures` 次后临时锁定

## 页面功能

| 页面 | 内容 |
|---|---|
| 仪表盘 | 运行概览（在线状态、运行时长、消息量、插件数量、延迟）、系统资源、消息趋势、最近日志 |
| 插件管理 | 官方/第三方分组、启停、热重载、安装/更新/卸载、在线配置表单 + TOML |
| 配置管理 | 本体 `config.toml` 表单/TOML 在线编辑、`.env` 编辑与密钥按需显示、模型注册表视图 |
| 系统状态 | 进程资源、宿主服务、后台任务、模型用量 |
| 机器人详情 | 昵称、QQ 号、在线状态、延迟、今日与累计消息量 |
| 日志 | 实时日志缓冲（保留 `log_buffer_size` 条） |

### 插件管理

- **官方插件**：随本体分发（`app/src/neobot_app/builtin_plugins/`），可启停、可重载，**不能**安装/更新/卸载
- **第三方插件**：位于数据目录 `plugins/`，可安装/更新/卸载/启停/重载
- 同名时官方插件优先，第三方副本被忽略
- 启停状态持久化在数据目录 `plugin_state.json`，与 `plugin.toml` 的 `enabled` 解耦
- **面板自身不能在面板内停用或重载**（会中断当前连接）：请修改 `config.toml` 的 `[dashboard].enabled`，或重启 NeoBot
- `dashboard.manage_plugins = false` 会关闭面板内的全部写操作（保存配置、显示密钥、管理插件、重启），只保留查看

插件开发与 `PluginControlFacade` 接口见 [07-插件开发](../07-插件开发.md)。

### 配置管理

- **本体配置**：`data/config.toml` 提供表单与 TOML 双视图在线编辑，保存前校验并备份到 `config_backup/`
- **环境变量**：`.env`（源码安装为 `app/.env`，打包部署为可执行文件同目录）在线编辑，密钥默认打码，需要时按需显示
- **模型注册表**：只读查看当前模型注册项（含生图模型列表）
- **重载运行时配置**：等价于 `config.reload` 管理命令，运行时按需读取的配置立即生效；构建期组件（运行中的 LLM Provider、关键词规则、TTS/表情包等）需要重启
- **重启 NeoBot**：优雅关闭并执行进程级重启，重新加载代码与配置，磁盘历史数据保留

### 远程管理

- `dashboard.allow_remote_manage = false` 时，非本机来源只能查看，不能改配置、编辑 `.env`、管理插件或重启
- 面板默认对网络开放，公网使用建议经 HTTPS 反向代理访问，并在确认 HTTPS 生效后设 `secure_cookies = true`
- 仅当可信反向代理正确覆盖客户端地址头时才开启 `trust_proxy_headers`

## 配置（`[dashboard]` 段）

```toml
[dashboard]
enabled = true                        # 是否启用网页面板（默认开启）
host = "0.0.0.0"                      # 监听地址；127.0.0.1 仅本机
port = 9981                           # 监听端口；占用时最多向后尝试 10 个
access_token = ""                     # 登录令牌；留空自动生成并写入 plugins_data/dashboard/access_token.txt
base_path = ""                        # 访问路径前缀，如 "/neobot"；留空为根路径
manage_plugins = true                 # 是否允许在面板内管理插件
allow_remote_manage = true            # 是否允许非本机来源执行管理操作
session_timeout_minutes = 720         # 会话过期时间（分钟）
log_buffer_size = 500                 # 日志缓冲条数
bot_info_cache_ttl = 300              # 机器人信息缓存秒数
history_max_days = 30                 # 消息统计历史保留天数
login_max_failures = 5                # 限速窗口内允许的登录失败次数
login_rate_limit_window_seconds = 600 # 登录限速窗口（秒）
secure_cookies = false                # 仅通过 HTTPS 发送登录 Cookie
trust_proxy_headers = false           # 是否信任反向代理提供的客户端地址头
```

> 字段含义与取值范围见 [05-配置参考](../05-配置参考.md)。

## 安全

- **令牌认证**：唯一长期凭据是访问令牌；会话为内存态，重启即失效
- **CSRF**：写操作必须携带与会话绑定的 CSRF 令牌（前端自动带）
- **登录限速**：[security.py](../../app/src/neobot_app/builtin_plugins/dashboard/security.py) 的 `LoginLimiter` 按 IP 统计失败次数并临时锁定
- **脱敏**：接口与日志输出统一经过 `redact`，避免密钥泄漏
- **防火墙**：`neobot firewall-open` 为面板端口添加 Windows 防火墙入站放行规则（需管理员权限，默认同时放行 9981）；外部无法连接时还要放行操作系统与云平台防火墙中的实际端口

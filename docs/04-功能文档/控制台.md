# 内置控制台

NeoBot 内置两个基于 **aiohttp** 的网页控制台，随主进程启停。

## 管理员控制台（本机）

- 默认开启（`console.admin_enabled`），固定监听 `127.0.0.1`，首选端口 `9891`
- 功能：
  - 管理配置（`data/config.toml`）
  - 管理 API 密钥（`.env`）
  - **保存并重载**：重新读取配置并创建新核心实例（记忆保存阶段不设总超时，页面持续等待控制台恢复）
  - **重启 Bot 核心**：优雅关闭当前核心并退出事件循环后，以原启动参数执行进程级重启；重新加载代码和配置，不复用旧进程内存，保留磁盘历史数据（进程 ID 可能变化）

## 调试控制台（可对外）

- 默认关闭（`console.enabled`），可按需对外监听，首选端口 `9981`
- 功能：运行概览、聊天时间线、AI 输入/输出、后台任务、服务健康、实时日志、调试记录、**脱敏诊断导出**

## 配置（`console` 段）

```toml
[console]
enabled = false              # 是否启用可从外网访问的调试控制台
host = "0.0.0.0"             # 调试控制台监听地址
port = 9981                  # 调试控制台首选端口（占用时自动向后查找）
admin_enabled = true         # 是否启用仅本机可访问的管理员控制台
admin_port = 9891            # 管理员控制台首选端口
port_search_limit = 100      # 从首选端口开始查找的端口数量（最大 100）
session_timeout_minutes = 60 # 控制台无操作会话过期时间（分钟）
secure_cookies = false       # 仅通过 HTTPS 发送登录 Cookie
trust_proxy_headers = false  # 是否信任反向代理提供的客户端地址头
```

## 安全

- **密码认证**：首次打开任一控制台时要求创建密码（不限制长度/字符/格式）；密码文件位于数据目录 `console/auth.json`
- **登录限制**：[`console/security.py`](../../app/src/neobot_app/console/security.py) 提供 LoginLimiter（登录失败限流）、Session/SessionStore（会话管理）、is_loopback（回环地址校验）、redact（脱敏）
- **忘记密码**：控制台不提供网页修改；点击登录页「忘记密码？」可查看文件位置，删除 `console/auth.json` 后重启设置新密码
- **公网使用建议**：通过 HTTPS 反向代理访问，确认 HTTPS 生效后设 `secure_cookies = true`；仅当可信反向代理正确覆盖客户端地址头时开启 `trust_proxy_headers`
- **防火墙**：`neobot firewall-open` 命令为控制台端口添加 Windows 防火墙入站放行规则（需管理员权限）；外部无法连接时请放行操作系统与云平台防火墙中的实际端口

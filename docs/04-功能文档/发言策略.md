# 发言策略宿主服务

官方插件可以通过 `ctx.plugin_host.services.get("speaking_policy")` 获取共享发言策略注册器。
未注册策略时，消息发送保持原有行为。

`register(owner, evaluator)` 注册一个同步判定函数，返回可重复调用的注销函数。
`evaluator` 接收 `ConversationRef`，返回 `SpeakingDecision(allowed, reason="")`。
多个策略取交集；任意策略拒绝时停止判定，并记录拒绝原因。
插件卸载或热重载时应调用注销函数，避免遗留旧策略。

`evaluate(conversation)` 可在生成内容前提前判断。OneBot 和本地适配器仍会在发送时检查，
覆盖普通消息、图片、语音、文件及合并转发，以及对应的原始 `call_api` 调用。
拒绝发送时抛出 `SpeechBlocked`，不产生成功回执；点赞和查询等操作不参与消息策略。
策略拒绝不会修改睡眠或待机状态。

管理命令可以在 `with policy.bypass("speaking_schedule"):` 范围内直接 `await` 回复。
该范围只绕过对应 owner，其他策略仍然生效。范围结束立即撤销权限，即使后台任务继承了上下文，
也不能在命令结束后继续使用绕过权限。不要在该范围内启动后台发送任务。
绕过上下文支持 OneBot 接收线程的同步调用转发。

注册器随插件主机复用，软重启时适配器绑定相同实例。此服务不引入新的配置项。

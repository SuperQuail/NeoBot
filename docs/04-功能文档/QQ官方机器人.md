# QQ 官方机器人

NeoBot 支持两种 QQ 接入通道：

- **OneBot**（默认）：NapCat 等第三方框架通过反向 WebSocket 连入，功能最全。
- **official**：直接使用 QQ 官方机器人 API v2（AppID/AppSecret 或手机 QQ 扫码绑定），无需第三方框架。

两种通道可以同时配置，但**同一时间只运行一套**；面板「机器人通道」页可以查看状态并原地热切换（不软重启、不重建运行时、面板不掉线）。

## 快速开始

1. 启动 NeoBot，打开网页面板，左侧进入「机器人通道」。
2. 官方卡片点「使用官方并扫码」：
   - 未绑定凭据时，页面显示二维码；控制台同时打印 ASCII 二维码与绑定 URL。
   - 手机 QQ 扫码（或打开 URL）完成绑定；凭据自动保存到 `data/qqbot/credentials.json`，之后启动不再扫码。
3. 也可以不用扫码：在 `config.toml` 的 `[adapter]` 填 `qq_appid` / `qq_client_secret`（或用环境变量 `NEOBOT_QQ_APPID` / `NEOBOT_QQ_SECRET`），保存后热重载即可。
4. 要切回第三方框架：在「机器人通道」选 OneBot，或把 `[adapter].mode` 改成 `onebot` 后重载配置。两种方式都会原地停掉旧后端、启动新后端。

## 身份判定与账号

- 判定只在**连接建立后**进行：适配器调用 `get_version_info`，`app_name` 为 `NeoBot-QQOfficial` 即官方通道；未连接不判定、不猜测。
- `[bot].official_mode`：`auto`（默认，按通道判定）/ `official` / `unofficial`（强制）。强制值只影响 Bot 行为，不改变实际协议。
- `[bot].account = 0`（默认）时，连接成功后用 `get_login_info` 自动获取机器人 QQ 号，写进运行期配置并同步消息队列；**不会回写 config.toml**。手动填了非 0 值时以配置为准，日志会提示 API 实际账号。
- 官方通道的官方行为：群消息一律按「@ 机器人」处理（官方群事件本身只推 @ 消息），提示词会注入官方机器人的能力边界。

## 热重载

| 改动 | 生效方式 |
|---|---|
| 面板切换通道 / 改 `[adapter].mode` + 重载 | 可切换适配器门面原地停旧后端、启新后端；不软重启、不重建运行期对象 |
| `qq_appid` / `qq_client_secret` / `qq_markdown` 等 | 热重载：当前是官方模式则原地重启官方后端（重新取 token/连网关） |
| OneBot 反向 WS 地址/端口/token | 热重载：只重启 OneBot 后端，失败回滚 |
| `[bot].official_mode`、`[bot].account` | 热重载：身份服务按新配置重新判定/回填，队列同步 |
| 扫码绑定 / 重新扫码 | 运行期完成；新凭据成功后才切换连接，失败保留旧连接 |

切换会断开被换下的那条连接（OneBot 停止监听 / 官方 WS 关闭），这是换通道本身的代价；切换期间发送会返回「适配器正在切换通道」，不会静默丢消息。

## 官方通道的能力与限制

- **被动回复窗口**：群消息 5 分钟内最多回复 4 条，单聊 60 分钟内最多 3 条（官方上限 5/4，留一次余量）。超限或过期自动转主动消息，并在每个会话只告警一次。
- **文本**：默认按 Markdown 发送；官方拒绝 markdown 时自动降级纯文本重发一次。单条超过 4000 字会按安全边界切分。
- **图片**：支持发送（URL 上传，失败回退分片上传）；语音/文件/视频尽力支持，失败会返回明确错误。
- **收消息**：文本、图片附件、语音 ASR 文本（没有 ASR 时给出占位）、引用消息；群全量消息需要平台权限，默认只收 @ 消息。
- **缺失接口降级**：没有好友列表/群列表；群信息与群成员接口多数需要白名单，适配器返回空数据而不是报错；没有单条消息查询接口，`get_msg` 只能查最近约 200 条本地缓存。
- **不支持的动作**（群管理、好友管理、踢人/禁言/精华、合并转发、频道/子频道等）会明确返回「官方平台不支持」，不会静默失败。
- **openid 与合成 ID**：官方只给用户/群的 openid，NeoBot 内部把它们映射成持久化的合成整数（`data/qqbot/identities.json`，新映射会写 INFO 日志）；同一人在单聊与群聊的 openid 不同，会对应两个合成号。需要在群名单、回复黑名单里填 ID 时，用日志/面板里看到的合成号。
- **非目标**：QQ 频道/频道私信、Webhook 模式、流式消息、内嵌键盘/按钮/ARK、互动回调。

## 排查

- **不出现二维码**：检查 `[adapter].mode` 是否为 `official`，以及凭据文件是否已存在（已绑定则直接连接）；控制台/日志会打印绑定 URL 与失败原因。
- **扫码后仍不连接**：看日志里的 token/网关错误与 close code：`4004` 刷新 token 重连、`4006/4007/4009` 清会话重连、`4008` 限频退避、`4914/4915` 机器人离线/封禁（停止重连）。
- **面板切换失败**：配置已经写入但适配器回滚到旧通道；页面会显示 reload 失败原因，重试或检查目标通道配置。
- **没收到群消息**：官方默认只推送 @ 机器人的群消息；群全量消息需要在开放平台申请权限。
- **图片发送失败**：看是否超过单文件上限或触发每日上传配额（错误码 40093002）；日志会带中文原因。

## 凭据与安全

- 官方 AppSecret 只写在 config.toml / `.env` / 扫码生成的 `data/qqbot/credentials.json`（0600、原子写）；**不会写进日志**。
- 扫码绑定的中间密钥只用于本次解密，不落盘。
- 不要把 `.env`、凭据文件或真实 openid 提交进仓库。

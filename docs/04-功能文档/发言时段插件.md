# 发言时段插件

官方插件 `speaking_schedule` 按星期和会话限制机器人发言，出厂停用。在插件管理中启用后立即注册发言策略；停用或卸载会撤销策略、事件订阅、配置消费者和 `/作息` 命令。

插件只控制发言许可，不更改睡眠状态，不停止接收消息。具体拦截入口见[发言策略](发言策略.md)。多个插件策略共同生效，任一策略拒绝就不能发送。

自动图片理解及 `parse_image` 工具也遵守当前会话的发言策略：静默时不启动解析，视觉 API 调用前再次检查，避免下载期间跨入静默后仍调用模型。跳过时保留原图片，不排队补解析；已经发出的 API 请求不会撤回。未启用策略时保持原行为，档案总结等其他后台任务不受此图片检查影响。

## 配置日程

配置位于 `plugins_data/speaking_schedule/config.toml`，与本体配置、插件启停状态分别保存。面板保存和管理命令修改均立即生效，无须重启。字段详见[配置参考](../05-配置参考.md#speaking_schedule-发言时段插件)。

```toml
timezone = "Asia/Shanghai"

[[windows]]
weekdays = [1, 2, 3, 4, 5]
start = "09:00"
end = "18:00"

[[windows]]
weekdays = [6, 7]
start = "22:00"
end = "02:00"
next_day = true

[[overrides]]
kind = "group"
id = "123456"
windows = []
```

星期 1–7 表示周一至周日。以上默认工作日 09:00 至 18:00、周六和周日 22:00 至次日 02:00 允许发言；指定群的空覆盖表示该群不限日程。私聊与群即使 ID 相同也相互独立。

起点包含，终点不包含；未填写 `next_day` 时必须同日且结束晚于开始。只有 `next_day = true` 才跨夜，持续时间必须大于零且小于 24 小时；相同端点非法。可填写多个不重叠时段，校验包含前日跨夜及周日到周一。相邻时段允许。`windows = []` 表示无限制；存在会话覆盖时，整个替换默认时段，同一会话不能重复覆盖。

## 管理命令

超级管理员和次级管理员均可使用，权限复用本体管理员配置。普通用户无法修改或通过命令绕过限制。

| 命令 | 行为 |
| --- | --- |
| `/作息 状态` | 显示当前会话的允许状态或限制原因、时区、下一日程边界、静默剩余秒数及时间健康 |
| `/作息 设置 默认 1,2,3,4,5 09:00-18:00` | 替换默认日程为该时段 |
| `/作息 设置 本群 6,7 22:00-02:00 次日` | 替换当前群覆盖，需在群内执行 |
| `/作息 设置 本私聊 1,2,3,4,5 10:00-17:00` | 替换当前私聊覆盖，需在私聊执行 |
| `/作息 静默 默认 30m` | 对本机器人账号的所有会话临时静默 |
| `/作息 静默 本群 2h` | 对本机器人账号的当前群临时静默 |
| `/作息 恢复 本群` | 解除当前群的临时静默 |

静默和恢复的范围也支持 `默认`、`本群`、`本私聊`，本群和本私聊必须与所在会话一致。时长为正整数加 `s`、`m`、`h`、`d`，最多 365 天。默认静默和会话静默同时存在时，解除会话静默不会解除默认静默。恢复只清除指定范围的临时静默，日程继续生效，也不会唤醒睡眠。

设置命令每次保存一个时段；多时段、空规则或删除覆盖请编辑插件配置。非法参数返回固定帮助。命令结果通过插件直接发送，只在这次发送期间绕过本插件策略；其他策略仍生效。静默期间管理员仍可查询和修改。传输故障仍按宿主发送流程处理。

## 持久化与时间健康

临时静默按机器人账号及范围保存在插件数据目录的 `mutes.json`，存储 UTC 截止时间。运行时用单调时钟倒计时，系统校时不会改变本次进程内剩余时间；重启后依据 UTC 截止恢复，已过期记录不恢复。账号来自宿主配置服务的 `bot.account`，切换账号后互不继承静默或时间样本。

日程始终依据服务器时间和配置时区执行。OneBot 事件时间仅作健康检查：只采样当前账号，拒绝无效时间、重复或倒序样本、偏差超过 120 秒的样本；有效样本超过 300 秒未更新显示过期。异常会告警，不更改系统时钟或执行时间。状态页的下一日程边界不包含静默截止，静默截止通过剩余秒数显示。

日程及静默写入采用临时文件、刷盘和原子替换，写入失败保留旧状态。日程写入保留已有顶层注释和未变更时段、会话覆盖的注释；被替换的具体时段不保留旧字段注释。损坏的静默状态文件会阻止插件加载，需先检查并修复该插件的数据文件。

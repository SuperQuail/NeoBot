# 01 项目概览

## 项目定位

NeoBot 是一个基于 **Python 3.13** 的 **QQ 聊天机器人**。它通过 OneBot 协议（如 NapCat 等框架）接入 QQ，以 LLM（大语言模型）为核心驱动，扮演一个「有性格、有记忆、会主动互动」的 AI 群友/好友。

与传统的命令式 QQ 机器人不同，NeoBot 的核心是一个 **Agent 系统**：主对话模型在提示词约束下自主决定是否回复、调用哪些工具、委托哪些子 Agent 完成任务。

- 项目名：`neobot`
- 当前版本：`1.0.0-alpha.18`（[语义化版本](https://semver.org/lang/zh-CN/)）
- 许可证：[LICENSE](../LICENSE)
- 安装方式：`pip install neobot-app`（PyPI）或源码运行（uv workspace）

## 技术栈

| 类别 | 技术 |
|---|---|
| 语言/运行时 | Python ≥ 3.13 |
| 包管理 | [uv](https://docs.astral.sh/uv/) workspace（monorepo） |
| 协议接入 | OneBot 11（WebSocket 反向连接）+ 本地 HTTP/WebSocket 适配器 |
| LLM Provider | DeepSeek（官方/OpenAI 兼容）、OpenAI、Anthropic、硅基流动（视觉/TTS/生图） |
| 存储 | SQLAlchemy 2.0（async）+ SQLite（默认）/ 其他支持的方言，Alembic 迁移 |
| 浏览器 | DrissionPage（4.x）+ Playwright |
| 控制台 | aiohttp Web 服务 |
| 文档处理 | pypdf、python-docx、openpyxl、xlsxwriter、pikepdf、markdown、fpdf2 等 |
| 质量工具 | pytest + pytest-asyncio、ruff、mypy、PyInstaller（打包） |

## 核心概念速览

- **OneBot 适配器**：NeoBot 通过 WebSocket 反向连接 OneBot 框架（如 NapCat），接收 QQ 消息事件并调用 API 发送消息；另有本地适配器用于测试。
- **Agent 模式**：默认回复模式。主模型在提示词约束下自主判断是否回复、如何回复、调用哪些工具。
- **Skill（技能）**：以 OpenAI function-calling 工具的形式注入给模型的能力模块，工具名自动加 `{skill_name}__` 前缀。
- **子 Agent**：专职完成某一类任务（解题、记忆、绘图等）的独立 LLM 会话，主 Agent 通过 delegate 工具委托。
- **档案（Archive）**：Bot 对某个用户/群/关键词的长期记忆条目，由记忆 Agent 自动总结写入。

# 05 配置参考

NeoBot 的主配置为 TOML 文件 `data/config.toml`，敏感信息（API 密钥）放在 `.env`。配置文件结构由 [`app/src/neobot_app/config/schemas/bot.py`](../app/src/neobot_app/config/schemas/bot.py)（`BotConfig` dataclass）定义，以下为各配置段说明。默认值以首次生成的文件为准。

> 本文档按 `BotConfig` 字段顺序组织。配置加载器会自动迁移旧版本配置并备份（`config/loader/`）。

## 顶层结构

```toml
version = "0.3.0"   # 配置文件版本

[bot]        # 机器人基础
[chat]       # 聊天与回复（含提示词模板）
[models]     # 模型注册表
[agent_model] # Agent 模型编号路由
[willing]    # 回复意愿
[tts]        # 语音合成
[plugins]    # 插件系统
[message]    # 消息处理
[file_server] # 文件服务器
[adapter]    # 协议适配
[debug]      # 调试
[console]    # 内置控制台
[scheduled_task] # 定时任务
[agent]      # Agent 系统（含子段）
[web_search] # 联网搜索
```

## [bot] 机器人基础

| 字段 | 默认值 | 说明 |
|---|---|---|
| `account` | 0 | 机器人 QQ 号 |
| `nick_name` | Neo Bot | Bot 昵称 |
| `alias_name` | ["Neo", "铸币bot"] | Bot 别称 |
| `bot_data` | 人设文本 | 描述机器人的人设 |
| `enable_bot_get_married` | false | 是否允许 Bot 与好友结婚（互动彩蛋） |

| `agent_max_iterations` | 200 | Agent 单轮回复最大工具迭代次数 |
| `group_agent_silent_timeout_seconds` | 60.0 | 群聊回复管线最长静默时间 |

| `ai_reply_check` / `ai_reply_check_lightweight` | false / true | AI 回复检查（全量/轻量） |
| `long_reply_fallback_template` | 模板 | 回复过长时默认回复 |
| `long_reply_max_length` | 300 | 回复最大字符数 |
| `long_reply_max_sentence_count` | 12 | 自动切分最大消息条数 |
| `enable_ai_reply_regenerate_on_length_limit` | true | 超限时让 AI 重新生成简短版 |
| `emoji_page_size` | 50 | 表情包列表每页数量 |
| `enable_last_reply_tracking` | true | 上次回复位置追踪 |
| `archive_fetch_window` | 20 | 档案获取窗口 |
| `poke_weight` | 0.2 | 戳一戳事件权重 |
| `reaction_weight` | 0.2 | 回应事件权重 |
| `official_bot_reply_coefficient` | 0.05 | 官方 Bot 消息的回复概率系数（基础概率乘以此系数） |
| `private_chat_suspend_wait_seconds` | 300 | 私聊回复后挂起等待秒数；超时无新消息则结束会话 |
| `private_chat_max_tokens` | 50000 | 私聊会话最大 Token 数；超过后重启聊天管线 |
| `private_chat_dynamic_warmup` | true | 首次收到私聊消息时是否动态预热历史消息 |
| `private_chat_warmup_history_count` | 100 | 私聊动态预热时拉取的历史消息条数 |
| `private_chat_new_message_collect_seconds` | 5.0 | 私聊挂起期间收到新消息后继续收集的时间窗口（秒） |
| `private_chat_reply_delay_seconds` | 5.0 | 私聊收到消息后延迟回复的秒数（期间收集后续消息） |
| `post_reply_message_timeout_seconds` | 60.0 | 群聊回复期间收集的消息超时秒数；超过不触发回复意愿判断 |
| `forward_message_display_threshold` | 50 | 合并转发节点数阈值；小于此值直接显示内容，否则仅显示 ID 并提供读取工具 |
| `forward_message_queue_weight` | 2 | 合并转发消息占用的队列位置数 |
| `forward_message_max_nesting` | 10 | 合并转发消息最大嵌套层级 |
| `wait_cooldown_seconds` | 60 | wait 工具调用冷却秒数 |
| `group_chat_reply_lifespan` | 5 | 群聊回复管线寿命（每次回复 -1，归零销毁；0 表示回复后立即销毁） |
| `group_chat_resume_prompt_template` | 模板 | 群聊回复管线续接提示词模板 |
| `group_chat_suspend_wait_seconds` | 3600 | 群聊回复后挂起等待秒数；超时无新消息则结束会话 |
| `enable_balance_check` | false | 是否启用 DeepSeek 余额检查与低余额预警（需配置管理员账户） |
| `balance_threshold` | 1.0 | 余额预警阈值（CNY），低于此值发送私聊通知 |
| `admin_accounts` | [] | 管理员 QQ 号列表，用于接收余额不足等系统通知 |
| `balance_check_cooldown_seconds` | 300 | 余额检查冷却秒数 |

### 关键词规则（`chat.key_word`）

```toml
[[chat.key_word]]
enabled = true
keywords = ["妈妈", "妈"]
prompt_list = ["你可以反问对方是不是叫夏亚"]
ignore_case = true
match_mode = "any"   # any / all
min_depth = -1
max_depth = 0
description = ""
```

## [models] 模型注册表

| 字段 | 说明 |
|---|---|
| `primary_chat_model` | 主对话模型（Agent 编号 0） |
| `agent_model_1` / `agent_model_2` / `agent_model_3` | 子 Agent 模型（编号 1-3，不同推理强度） |
| `vision_model` | 图像识别模型 |
| `tts_model` | 语音模型 |
| `creator_image_model` | 创作者生图模型 |

每个模型注册项结构：

```toml
[models.primary_chat_model]
description = "主对话模型"
provider = "DeepSeek"        # DeepSeek / OpenAI / Anthropic / SiliconFlow
model_name = "deepseek-v4-pro"

[models.primary_chat_model.settings]
temperature = 1.0
max_output_tokens = 2048
timeout_seconds = 120.0
top_p = 1.0
frequency_penalty = 0.0
presence_penalty = 0.0

# DeepSeek 特有（OpenAI 样式，程序自动转换）
deepseek_thinking_mode = "enabled"      # enabled / disabled / random
deepseek_reasoning_effort = "max"       # high / max
deepseek_random_thinking_probability = 0.6

[models.primary_chat_model.pricing]
input_price_per_mtokens = 0.0
output_price_per_mtokens = 0.0
cache_hit_price_per_mtokens = 0.0
billing_metric = ""                     # 非 Token 计费标识
```

## .env 环境变量

| 变量 | 说明 |
|---|---|
| 各平台 `API_KEY` 类变量 | LLM/视觉/TTS/生图平台密钥（DeepSeek、OpenAI、Anthropic、硅基流动等） |
| `NEOBOT_DATA_DIR` | 数据目录覆盖（默认 `app/data/`） |
| `NEOBOT_ENV_FILE` | 环境变量文件路径覆盖（默认数据目录下的 `.env`） |
| `NEOBOT_LOCAL_ADAPTER_HOST` / `NEOBOT_LOCAL_ADAPTER_PORT` | 本地适配器监听地址/端口覆盖（对应 `adapter.local_host` / `local_port`） |

> 完整变量清单以首次生成的 `.env.example` 与 [`config/loader/env.py`](../app/src/neobot_app/config/loader/env.py) 为准。

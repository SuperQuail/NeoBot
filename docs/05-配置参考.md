# 05 配置参考

NeoBot 的主配置为 TOML 文件 `data/config.toml`，敏感信息（API 密钥）放在 `.env`。配置文件结构由 [`app/src/neobot_app/config/schemas/bot.py`](../app/src/neobot_app/config/schemas/bot.py)（`BotConfig` dataclass）定义，以下为各配置段说明。默认值以首次生成的文件为准。

> 本文档按 `BotConfig` 字段顺序组织。配置加载器会自动迁移旧版本配置并备份（`config/loader/`），当前配置版本为 **0.6.0**，支持链式迁移（0.3.0 → 0.4.0 → 0.5.0 → 0.6.0）：0.4.0 → 0.5.0 把 `[console]` 迁移为 `[dashboard]`；0.5.0 → 0.6.0 把旧的各角色内联模型配置（`[models.primary_chat_model]` 等）搬进 **模型库** `[[models.registry]]`，并生成 `[models.assignments]` 记录各调用方引用的 key（未出现的角色自动补回默认模型）。

## 顶层结构

```toml
version = "0.6.0"   # 配置文件版本

[bot]        # 机器人基础
[chat]       # 聊天与回复（含提示词模板）
[models]     # 模型库 [[models.registry]] + 调用方引用 [models.assignments]
[agent_model] # Agent 模型编号路由
[willing]    # 回复意愿
[tts]        # 语音合成
[plugins]    # 插件系统
[message]    # 消息处理
[file_server] # 文件服务器
[adapter]    # 协议适配
[debug]      # 调试
[dashboard]  # 网页面板（官方内置插件）
[scheduled_task] # 定时任务
[agent]      # Agent 系统（含子段）
[web_search] # 联网搜索
```

## [models] 模型库与调用方引用

模型**单独存储在模型库**（`[[models.registry]]`），主对话 / Agent / 视觉 / TTS / 生图等**调用方只引用 key**（`[models.assignments]`）。同一个模型可被多个调用方复用，改一处即可全局生效。

```toml
# 模型库：每个模型一条，key 是调用方引用名（字母/数字/下划线/点/短横线）
[[models.registry]]
key = "deepseek-v4-pro"
model_type = "chat"           # chat / image / vision / tts / other（面板分组与筛选用）
description = "主对话模型（Agent模型编号0）"
provider = "DeepSeek"         # DeepSeek / OpenAI / Anthropic / SiliconFlow …
model_name = "deepseek-v4-pro"
native_vision = false          # 是否原生支持图片；主推理模型开启后不可用时自动回退 vision_model
use_system_proxy = false       # 该模型是否跟随系统/环境变量代理访问；默认关闭（直连）
balance_query_hint = ""        # 该模型的余额查询方式（请求地址/方法/鉴权/返回字段）；留空表示无查询提示

[models.registry.settings]
temperature = 1.0
max_output_tokens = 2048
timeout_seconds = 120.0
top_p = 1.0
frequency_penalty = 0.0
presence_penalty = 0.0

# DeepSeek 特有（OpenAI 样式，程序自动转换）
deepseek_thinking_mode = "enabled"      # enabled / disabled / random
deepseek_reasoning_effort = "max"       # high / max
deepseek_random_thinking_probability = 0.6

[models.registry.pricing]
input_price_per_mtokens = 0.0
output_price_per_mtokens = 0.0
cache_hit_price_per_mtokens = 0.0
billing_metric = ""                     # 非 Token 计费标识

# 调用方：值为上面定义的 key
[models.assignments]
primary_chat_model = "deepseek-v4-pro"      # 主对话模型（Agent 编号 0）
agent_model_1 = "deepseek-v4-flash-max"     # 子 Agent 模型（编号 1-3，不同推理强度）
agent_model_2 = "deepseek-v4-flash-high"
agent_model_3 = "deepseek-v4-flash-off"
vision_model = "qwen3-vl-8b"                # 图像识别模型（不可用时降级）
tts_model = "cosyvoice2"                    # 语音模型（TTS 关闭时不注册）
creator_image_models = ["flux-schnell"]     # 创作者生图模型（可多个，引用 key）
```

- 默认模型库包含 4 个对话模型（`deepseek-v4-pro` / `deepseek-v4-flash-max` / `deepseek-v4-flash-high` / `deepseek-v4-flash-off`）、视觉 `qwen3-vl-8b`、TTS `cosyvoice2`、生图 `flux-schnell`
- 调用方引用了不存在的 key 时：必需角色（主对话 / Agent 1-3）直接报错并列出全部问题；`vision_model` / `tts_model` 仅告警并降级禁用
- 生图分配了多个 key 时，`draw` 工具会新增 `provider` 参数，Agent 可用序号/描述/供应商/模型名指定服务；未指定时使用列表第一项
- `balance_query_hint` 是纯文本提示，可写请求地址、方法、鉴权方式与返回字段。它只用于生成**按需读取**的 Markdown 技能 `balance-query`：该技能只列出配置了提示的模型，末尾固定追加「未显示查询方式则代表无查询提示」；配套 `balance_query` 技能提供 `balance_query__http_request` 工具（限制请求方法、响应体积与超时，默认只允许公网地址，查询自建/局域网地址需传 `allow_private=true`）
- `model_type` 只影响面板中的分组、筛选与排序（例如生图角色优先列出 `image` 类型），不限制调用方引用；留空时按类型自动生成描述
- 模型条目不保存任何密钥：API Key 一律来自 `.env` 的 `<供应商>_APIKey`，面板中的「供应商 Key」状态即该变量是否配置
- `use_system_proxy` 默认关闭：模型请求直连，不读取 `HTTP_PROXY`/系统代理；仅在需要通过本地代理（如 Clash）访问供应商时按模型开启。开启后主对话/Agent/视觉/生图/TTS 请求以及面板的连通性测试都会走系统代理
- 网页面板的「模型库」「模型分配」面板提供同样的增删改与改绑能力，无需手写 TOML，并支持逐条「测试」连通性（见 [04-功能文档/网页面板](04-功能文档/网页面板.md)）

## [agent_model] Agent 模型编号路由

| 字段 | 默认 | 说明 |
|---|---|---|
| `main_agent` | 0 | 主回复 Agent 模型编号 |
| `creator` | 1 | Creator Agent |
| `memory` | 1 | 记忆 Agent |
| `chat_interaction` | 1 | 聊天互动 Agent |
| `willingness` | 1 | 回复意愿 Agent |
| `scheduled_task` | 1 | 定时任务 Agent |
| `archive_summary` | 1 | 档案自动总结 |
| `self_heal` | 3 | 自修复 Agent（默认低成本非推理模型） |

主推理原生视觉开关位于 `agent_model.main_agent` 所引用的模型库条目，而不是独立的 `vision_model` 条目。例如：

```toml
[[models.registry]]
key = "deepseek-vision-exp"
provider = "DeepSeek"
model_name = "deepseek-v4-flash-vision-exp"
native_vision = true

[models.assignments]
primary_chat_model = "deepseek-vision-exp"

[agent_model]
main_agent = 0
```

回退路由固定为 `[models.assignments].vision_model` 引用的模型，**无需也不支持再手选回退模型编号**：

- 主模型创建失败（密钥/网络/配置错误）→ 自动改用视觉模型作为对话模型，Bot 继续正常回复；
- 主模型声明原生视觉但实际无法处理图片 → 自动切换到视觉模型并**保留图片**（视觉模型本身能看图）；
- 视觉模型也不可用时才会提示「当前主回复模型不可用」。

不要重复添加已有 TOML 分区，应修改对应字段。配置保存后重载 Bot 核心生效。运行中降级不会改写配置；重载后会重新尝试原生视觉。工具、图片来源及限制见[图像与多媒体](04-功能文档/图像与多媒体.md)。

## [plugins] 插件系统

| 字段 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 是否启用第三方插件；官方插件（网页面板）始终加载 |

## [dashboard] 网页面板

网页面板是官方内置插件 `dashboard`，配置来自本体 `config.toml` 的本分区（**不是**插件的 `plugin.toml`）。功能与使用方式见 [04-功能文档/网页面板](04-功能文档/网页面板.md)。

登录密码不在本分区配置：未设置密码时不允许外网访问，只能在本机打开面板按提示设置，或由超级管理员在 QQ 私聊发送 `/set_password <新密码>` 设置。密码以 PBKDF2 哈希保存在数据目录 `plugins_data/dashboard/auth.json`。

| 字段 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 是否启用网页面板 |
| `host` | 0.0.0.0 | 监听地址；`0.0.0.0` 对网络开放（默认），`127.0.0.1` 仅本机 |
| `port` | 9981 | 监听端口；被占用时最多向后尝试 10 个端口并打印告警 |
| `base_path` | "" | 访问路径前缀（如 `/neobot`）；留空表示直接以根路径访问 |
| `manage_plugins` | true | 是否允许在面板内执行管理操作（插件管理、保存配置、模型库/分配、添加供应商、重启）；关闭后仅可查看 |
| `allow_remote_manage` | true | 是否允许非本机来源执行管理操作（改配置、改 `.env`、插件管理、重启）；关闭后远程只能查看 |
| `session_timeout_minutes` | 720 | 面板无操作会话过期时间（5-10080 分钟） |
| `log_buffer_size` | 500 | 面板保留的日志缓冲条数（1-10000） |
| `bot_info_cache_ttl` | 300 | 机器人信息缓存秒数（0-86400） |
| `history_max_days` | 30 | 消息统计历史保留天数（1-3650） |
| `login_max_failures` | 5 | 同一 IP 在限速窗口内允许的登录失败次数（≥1） |
| `login_rate_limit_window_seconds` | 600 | 登录限速窗口（秒，≥1） |
| `secure_cookies` | false | 仅通过 HTTPS 发送登录 Cookie；使用 HTTPS 反向代理时开启 |
| `trust_proxy_headers` | false | 是否信任反向代理提供的客户端地址头 |
